素材与边界

  • 盘面：真实 BoardView 投影同一份只读快照，候选弧与高亮连线也是真实投影。
  • 操作按钮与「上一招」：真实组件、真实候选；按钮为静态展示，点击不结算。
  • 角色：仓库现有占位素材 minigame/assets/characters.png，非最终画风，也不代表《弈仙牌》精细度已达成。
  • 背景：当前游戏已有的 drawLandscape；页面只另加了少量线条与淡雾草图。两者都只是氛围，不代表最终画面或《弈仙牌》那样的精细度。

操作

  • ← / → 或底部切换条：上一个 / 下一个布局；1 / 2 / 3 直达。
  • 地址栏带 ?variant=A|B|C，刷新保持；可分享。
  • 可选 &seed=、&round= 换一份可复现快照。

原型静止：动作按钮只展示排版，点击不会执行、不会改盘。

# 归元弈

## 游戏背景

归元弈是一款基于中国传统五行哲学的策略游戏。你要调度金、木、水、火、土五行各自的阴阳两侧，追求阴阳调和、五行圆满的“归元”境界。

---

## 核心机制

### 五行相生相克

五行之间相生相克，循环不息：

**相生**：木生火 → 火生土 → 土生金 → 金生水 → 水生木

**相克**：木克土 → 火克金 → 土克水 → 金克木 → 水克火

### 天干与阴阳

五行各有阴阳两种形态，用十天干来表示：

| 五行 | 阳 | 阴 |
|------|----|----|
| 木 | 甲 | 乙 |
| 火 | 丙 | 丁 |
| 土 | 戊 | 己 |
| 金 | 庚 | 辛 |
| 水 | 壬 | 癸 |

### 节点状态

每个节点都有“阳”和“阴”两个独立的等级。当两侧都达到点亮时，就实现了**归一**。各档位的名称与含义见 [`GLOSSARY.md`](GLOSSARY.md)，规则见 [`docs/GDD.md`](docs/GDD.md) §2.2。

---

## 游戏玩法

游戏按**大回合**推进：每个大回合由先手、后手各一个半回合组成。大回合上限与终局判定见 [`docs/GDD.md`](docs/GDD.md) §2.1。

每个半回合会随机抽取一个天干，飞向对应的五行节点，你据此决定这一手怎么走。

**游戏目标**：优先让所有五行节点都达到归一状态；打到上限仍无人达成时按累计总分决胜（见 [`docs/GDD.md`](docs/GDD.md) §2.1）。

**游戏模式**：当前只实装「玩家 VS 天道」（单人对战 AI）；其余规划中的模式见 [`docs/GDD.md`](docs/GDD.md) §3。

---

## 你能做的动作

**调息**、**化**、**破**，以及更强势的**强化**、**强破**。

每个动作的门槛、目标侧与消耗由规则决定，见 [`docs/GDD.md`](docs/GDD.md) §2.2 / §2.3；动作名的规范写法与禁用别名见 [`GLOSSARY.md`](GLOSSARY.md)。本文不复述规则。

---

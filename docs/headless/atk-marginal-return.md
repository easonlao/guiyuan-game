# 【破】(ATK) 盘面边际收益诊断

> Ticket 08 / spec `balance-audit-and-dominance`。本文是【破】盘面边际收益的**可复跑证伪记录**。
> 本诊断**剥离计分**：只测盘面价值，计分轴的作用由 ticket 09 单独测量。
> 指标口径的唯一来源是 `src/core/headless/Metrics.ts` 与 `docs/headless/metric-definitions.md`。

## 1. 复跑命令

```bash
npm run benchmark:atk-marginal
```

命令由 `package.json` 长期保留，入口是 `src/core/headless/AtkMarginalReturn.ts`（确定性，无随机种子）。

## 2. 口径：为什么它隔离盘面价值

**盘面边际收益**定义在 `Metrics.atkTempoGain`：

```
atkTempoGain(before, after)
  = countActionsToGuiYuan(after) - countActionsToGuiYuan(before)
```

即一次【破】使对手「还差几次行动到五行归元」（`actionsToGuiYuan`，ticket 07）**增加**的次数。

逐侧取值（由 `countActionsToGuiYuan` 的逐侧口径 `max(0, 1 - level)` 直接推出）：

| 命中前等级 | 命中后等级 | 边际收益 | 说明 |
| --- | --- | ---: | --- |
| 虚空 0 | 道损 -1 | **+1** | 对手点亮该侧从需 1 次行动变为需 2 次行动 |
| 点亮 1 | 虚空 0 | **+1** | 对手点亮该侧从 0 次行动变为需 1 次 |
| 加持 2 | 点亮 1 | **0** | 仍处于点亮，未点亮侧数与道损数均不变（加持吸收了这次打击） |
| 道损 -1 | 道损 -1（clamp） | **0** | 已封顶，盘面不再变化 |

**为什么隔离盘面价值：**

1. 口径的输入是两张 `BoardState`，只读节点等级；不接触分数、AI 权重、稀有度或任何 `PointsConfig`。
2. `ActionResolver.resolve` 对【破】只改动对手一侧等级（`0 → -1`、`1 → 0`、`2 → 1`），所以该差值恰好等于这一次盘面扰动的节奏价值。
3. 计分被剥离的验证写在 `tests/core/atk-marginal-return.test.ts`：同一动作在默认 `POINTS_CONFIG` 与全零 `PointsConfig` 下 `scoreDelta` 不同，但 `atkTempoGain` 逐字节一致。

方法只使用既有接缝：`ActionResolver.resolve`（场景接缝）、`BoardFixture.gameStateWith`、`Metrics.atkTempoGain`。**未新增第三处接缝。**

## 4. 结论：是否递减？拐点与封顶条件

**不是平滑递减，而是逐侧阶跃函数。** 单次【破】的盘面收益只由命中侧当前等级决定：

- 命中 `0` 或 `1` 的侧：**+1**（不随使用次数递减）；
- 首次命中 `2`（加持）的侧：**0**（加持吸收了这次打击）；
- 命中已 `-1` 的侧：**0**（该侧已封顶，游戏的目标选择会自动跳过它）。

因此：

- **使用次数维度**：从低位态期盘面出发，第 1 到第 10 次【破】的边际收益全部是 +1，**不存在递减**；第 11 次起为 0。
- **拐点**：唯一的「软拐点」是**加持**——对手把某侧建到 `2` 后，打在该侧上的第一次【破】收益为 0。中盘盘面的平均收益 0.938 正是这个拐点造成的（15 收益 / 16 次命中）。它不是「用得越多越弱」，而是「打在越厚的目标上越弱」。
- **封顶条件**：对手 10 侧全部道损 `-1`。此时盘面 `actionsToGuiYuan = 20`，已无合法【破】目标，边际收益 0。封顶与使用次数无关，只与对手是否还有非道损侧有关。

一个必须写明的细微修正：ticket 假设「封顶只发生在对手全道损时」。数据确认**硬封顶**确实只发生在全道损；但在硬封顶之前存在**加持软封顶**（首次命中加持侧收益 0）。这给「根据盘面在推进与压制之间切换」留下了一个真实的盘面信号：打加持侧是亏的，应该改打未建设侧。不过对纯压制策略而言，它只需在 0 收益后换一个目标，平均收益仍接近 1.0，因此这个信号不足以构成「递减收益」。

## 5. 与「把【破】提前到低位态导致崩坏」的机制对照

ADR 0010 记录的崩坏：变体 B 把【破】开放到低位态（`0` / `-1`）后，配合 2.5 倍攻击状态分，压制轴净收益过高，平衡策略归元率从 88.64% 跌到 21.18%，对局被拖入 30 回合分数结算。根因表述为「低位改道把【破】提前到 0/-1 阶段，与 2.5 倍攻击状态分叠加后使压制轴净收益过高」。

本曲线能解释该机制的**盘面一半**：

- 低位态期的盘面恰好是 10 侧全虚空。在这块盘面上，前 10 次【破】每一次都是干净的 +1，**没有加持可以吸收，也没有递减**，直到对手全道损才封顶。
- 因此「把【破】提前到低位态」等于把可用 +1 命中的数量从「对手已建设后才可打」扩大到「开局就能连打 10 次」。盘面层面，提前压制严格变强，没有任何自我限制。
- 这与 ADR 0010 的根因一致：提前兑现的压制轴在盘面上不亏，最优解必然是尽量多压制，「根据盘面在推进与压制之间切换」没有存在空间。

**但不能只靠本曲线解释全部崩坏。** 盘面收益是**封顶且有界**的（合计最多 10，封顶于全道损）；如果只有盘面价值，游戏不会崩到 21.18% 归元率。崩坏需要计分轴作为放大器：每次命中的 `CAUSE_DMG`/`BREAK_LIGHT`/`WEAKEN` 状态分让 AI 把「再多打一次」估值得远超其 +1 盘面节奏价值，且这些分数不随盘面封顶而饱和（在对手重建后仍可再赚）。**计分的净收益曲线由 ticket 09 单独测量**；本票的结论是：盘面曲线是崩坏的**必要前置**（提前压制在盘面上无递减、不亏），计分是**充分放大器**。

## 6. 复跑自检

- 全部断言在 `tests/core/atk-marginal-return.test.ts`：
  - 口径定义锁：`0→-1` 记 +1、`1→0` 记 +1、`2→1` 记 0、已道损记 0；
  - 计分剥离锁：默认计分与全零计分的 `scoreDelta` 不同，但盘面边际收益一致；
  - 序列不变量：每次收益为 0 或 +1，累计等于终点减起点，封顶时 `actionsToGuiYuan = 20`（10 侧全道损）。
- 报告中的数字由 `npm run benchmark:atk-marginal` 复跑得到；测试**不复述**报告数字，只锁定口径与不变量。

# 低位改道（变体 B）× 计分实验

本文件记录"低位改道（变体 B）"平衡性实验的实测数据与结论。工单 04（只调 AI 偏好）写第 1 节；工单 05（规则计分数值）将在本文件末尾追加第 2 节。

- 变体 B：抽中天干对应侧处于低位态（虚空 0 / 道损 -1）时，除原地【吸纳】外，阴天干可【化】向相生节点、阳天干可【破】向相克节点，代价是放弃本次原地 +1。默认关闭（`lowStateRedirect`）。
- 本票（04）只调 AI 决策权重，**不改动任何规则或计分默认**：计分始终为生产默认 `POINTS_CONFIG`，变体 B 仍默认关闭。

## 1. 工单 04：杠杆一——只调 AI 偏好（零规则代价）

### 1.1 方法与口径

| 项 | 取值 |
| --- | --- |
| 命令 | `npm run benchmark:ai-preference -- --matches 5000 --seed 10000 --max-rounds 30` |
| 种子基数 | `10000`，每格使用 `10000 + i` 连续 5000 局 |
| 每格样本量 | 5000 局（每格同一策略自对弈） |
| 回合上限 | 30 |
| 模式 | `off` = 变体 B 关闭；`full` = 变体 B 开启 |
| 计分配置 | 生产默认 `POINTS_CONFIG`（未做任何覆盖） |
| 4 组权重预设 | `平衡` = `balancedStrategy`、`归元冲刺` = `rushGuiyuanStrategy`、`激进压制` = `aggressiveStrategy`、`保守自保` = `defensiveStrategy`（均在 `src/core/ai/Strategy.ts`） |
| 补充对照 | `纯推进` = `pureRushStrategy`、`纯压制` = `pureSuppressStrategy`（只作补充行，不计入 4 组预设） |

指标口径：

- **归元率**：`endReason === 'GUI_YUAN'` 的对局占比。
- **回合上限率**：`endReason === 'MAX_ROUNDS'` 的对局占比（与归元率互补）。
- **平均回合**：`roundsPlayed` 的均值。
- **P1/P2 胜率**：`winner === 'P1' / 'P2'` 的占比（自对弈，双方使用同一策略）。
- **压制度量**：对手盘面等级下降量之和的场均，**加持 2 → 点亮 1 记 1**（按等级下降量统计，而非"未点亮侧数"；这是工单 03 明确防护的口径陷阱）。
- **低位态决策**：抽中天干对应侧在结算前满足 `playerBoard[tianGan.element][tianGan.polarity] <= 0` 的回合，计入低位态决策分布。

### 1.5 结论：仅靠 AI 偏好能否把 full 模式归元率拉回 ≥80%？

**不能（就 4 组权重预设而言）。** 4 组预设的 full 模式归元率为：

- 平衡 21.18%（较 off 掉 67.46pp）
- 归元冲刺 73.18%（较 off 掉 26.08pp）——**最好的现实预设，但仍低于 80% 门槛，且 26.82% 对局撞上 30 回合上限**
- 激进压制 0.00%（100% 回合上限）
- 保守自保 24.62%（较 off 掉 73.68pp）

唯一达到 ≥80% 的是补充行 **`纯推进`（pureRushStrategy）**，full 模式归元率 **99.00%**、回合上限率 1.00%、P1 胜率 50.26%（几乎无先后手倾斜）。但它**不是一个可采用的 AI 偏好**：

1. **策略结构退化**：`PURE_RUSH_WEIGHTS` 把压制轴（`breakOpponentGuiYi` / `causeDamage` / `suppressNode`）与规则得分轴（`scoreDeltaWeight`）全部置零，等于让 AI 对"破"与计分完全无感。它之所以在 full 模式下不受变体 B 拖累，恰恰是因为它**基本不使用新改道**——低位态决策 95.4% 走【吸纳】，仅 4.6% 走【化】，【破】为 0%。这不是"学会了与变体 B 共存"，而是"关掉了会受影响的轴"。
2. **游戏变成单人竞速**：该策略下 `off` 模式归元率本就 99.24%，"竞速归元"始终成立，压制对抗形同虚设，与变体 B 想引入的"改道选择"设计意图相悖。

因此本票的判定是：**AI 偏好杠杆不足以让变体 B 恢复健康**。它能把损失从 −67pp 收窄到 −26pp（归元冲刺），但收不回到 ≥80%；唯一"达标"的路径是把 AI 退化成只会推进的纯竞速策略，不具备可玩性。变体 B 的失衡根因不在 AI 偏好层，而在规则计分对"破/致敌跌损"的过度奖励。

### 1.6 交给工单 05 的计分参数假设

按嫌疑排序（均可用 `HeadlessMatch` 的 `scoreConfig` 注入做单变量对照）：

1. **【破】的动作分与"致敌跌损"状态分**：`ACTION.ATK = 40`，以及 `STATE_CHANGE.CAUSE_DMG`（阳 300 / 阴 250）、`BREAK_LIGHT`（阳 200 / 阴 150）、`WEAKEN = 200`。变体 B 把【破】开放到低位态（0 / -1）阶段，使压制轴的净收益被提前兑现；配合 `scoreDeltaWeight = 0.8`，AI 会大量改道去【破】（平衡 30.8%、激进 44.4% 的低位决策），把对局拖入 30 回合分数结算。假设：下调或归零【破】的净收益后，full 模式归元率显著回升。
2. **终局残留道损惩罚 `DAMAGE_PENALTY = 50`/道损**：使"打残对手"直接转化为回合上限时的分数优势，鼓励拖延。假设：下调或取消该惩罚可降低回合上限率。
3. **硬编码攻击强化倍率**：`STATE_CHANGE` 中已硬编码的 2.5 倍攻击压制得分，以及 `RARITY_MULTIPLIER = 1.5` 对 `ATK` 的稀有度加成（`ATK` 不在 `NO_RARITY_ACTIONS` 黑名单中）。假设：撤销攻击强化倍率 / 把 `ATK` 加入稀有度黑名单，检验"攻击净收益归零"。
4. **双角色耦合**：计分既是 AI 动作估值的输入，又是回合上限时的胜负判据，因此上述任一数值改动会同时影响 AI 行为与终局判定，05 需分别对照、避免归因混淆。
5. **补充线索**：`归元冲刺` 与 `纯推进` 的 full 模式差距（73.18% vs 99.00%）说明"降低压制权重"方向有效但不够；可把 05 的最小充分改动集限定在"攻击净收益归零 + 道损惩罚下调"的组合上。

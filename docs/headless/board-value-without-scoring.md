# 剥离计分后的盘面价值 (Board Value Without Scoring)

> Ticket 09。问题：激进压制对全部其它六个策略严格占优——这是**计分**造成的，还是**盘面节奏**造成的？
> 做法：用同一策略族、同一随机种子与样本量，在「计分轴完全关闭」的条件下重跑跨策略对拼矩阵，
> 与「计分轴开启」逐格对照。
>
> **结论（已修正）：激进压制的严格占优是计分造成的，不是盘面造成的。**
> 完全剥离计分（AI 不读计分 **且** 回合上限按盘面进度判定胜负）后，**没有任何策略严格占优**；
> 盘面本身偏好**推进**（`平衡` / `剥离计分` 各对 6 个对手赢 5 个），激进压制只赢 2 个。
> 高流局率与压制型先手优势同样由计分结算放大，不是纯盘面现象。

## 0. 本次修正（相对初版结论）

初版 board-only 只关闭了 **AI 对计分的读取**，回合上限结算仍用生产 `POINTS_CONFIG`。
因此约 44% 的 board-only 对局（回合上限局）的胜负由**计分**决定，结论并未真正剥离计分。
本次修正把终局结算也改为**盘面进度判定**（`MatchOptions.isBoardSettlement`），
在两个入口（AI 估值、终局结算）都剥离计分后重跑，**结论翻转**：

| | 初版 board-only（结算仍用计分） | 修正 board-only（结算也用盘面） |
| --- | --- | --- |
| 激进压制对全部六策略 | 严格占优 79.53%–82.93% | **只赢 2 个**（归元冲刺 52.55%、纯推进 52.94%） |
| 是否存在严格占优策略 | 是（激进压制） | **否**（无任一策略对全部六者 > 50%） |
| 盘面偏好 | 压制 | **推进**（平衡 / 剥离计分各 5/6） |
| 裁定 | 盘面造成 | **计分造成** |

## 复跑命令

```sh
# 两个模式都跑，直接输出本文件的「逐格对照」报告
npm run benchmark:board-value -- --matches 2000 --seed 10000 --max-rounds 30

# 只跑 board-only 矩阵（AI 不读计分 + 终局按盘面进度结算）
npm run benchmark:board-only -- --matches 2000 --seed 10000 --max-rounds 30

# 只跑计分轴开启矩阵（现状）
npm run benchmark:head-to-head -- --matches 2000 --seed 10000 --max-rounds 30
```

- 样本量：每座次每格 2000 局；每个有序策略对合计 4000 局；7 个策略 → 42 个有序对 → 每个模式 84,000 局；两个模式合计 168,000 局。
- 种子基数：`10000`（第 i 局用 `10000 + i`，两个模式、两个座次使用完全相同的种子序列）。
- 回合上限：30 大回合；计分配置：生产默认 `POINTS_CONFIG`（两模式相同）。
- 座次平衡胜率 = (A 胜场 + 0.5 × 平局) / 两座次总局数；A 对 B 与 B 对 A 严格互补。

## 口径与实现说明

### board-only 的完整语义（本次修正）

`board-only` 现在在两个层面剥离计分：

1. **AI 估值**：`RuleSwitches.isBoardOnly = true` 时 `ActionEvaluator` 的 `scoreDeltaPoints = 0`，
   AI 只按盘面权重判优。不改动作合法性、状态转移或候选集。
2. **终局结算**：`MatchOptions.isBoardSettlement = true` 时，回合上限（`MAX_ROUNDS`）的胜负
   **不读任何计分**，按盘面进度依次比较（`src/core/headless/HeadlessMatch.ts` 的 `settleMaxRoundsByBoard`）：
   1. `actionsToGuiYuan`（未点亮侧数 + 道损数，ticket 07 口径）少者胜；
   2. 相同则 `guiYiNodes`（阴阳均 >= 1 的节点数）多者胜；
   3. 仍相同则盘面无法区分，判 `DRAW`。

第 3 级用 `DRAW` 而不是沿用「平局后手胜」：实测回合上限局的盘面完全相同的比例很高
（部分对局对高达 ~87%），若用后手胜，胜负会被平局规则而非盘面价值决定，结论失真。
因此本报告的 `trueDrawRate`（真实平局率）非零，`seatBalancedWinRate` 按「胜场 + 0.5 × 平局」计入平局。

### 为什么这是「盘面价值」而不是另一种计分

盘面进度的口径是 **还差几次行动到五行归元**，即游戏真实胜负条件（五行归元）的距离下界；
它只读盘面等级，不接触任何 `PointsConfig` 字段。第 1 级 `actionsToGuiYuan` 是 ticket 07/08/09
一直使用的唯一盘面进度口径，本次未新增指标定义。

### 敏感性：另一种「盘面结算」会保留初版结论

若把终局结算改为「残留道损少者胜」（即只保留 `DAMAGE_PENALTY`、把其余计分清零），
激进压制仍对全部六策略占优（52.45%–64.00%，对剥离计分 50.15% 临界）。差异来自口径：
道损数只统计等级 -1 的侧，忽略了未点亮侧；一个「0 道损但有 8 侧虚空」的盘面在道损口径下
优于「2 道损但只剩 2 侧虚空」的盘面，但在 `actionsToGuiYuan` 口径下更差。
本报告以 `actionsToGuiYuan`（距五行归元）为准，因为它是游戏真实胜负条件的距离，
且道损口径仍会读取 `DAMAGE_PENALTY` 这一计分参数，不是「完全剥离计分」。

### 对照自检

`纯推进`、`纯压制`、`剥离计分` 的 `scoreDeltaWeight` 均为 0，两模式下 **AI 决策逐字节相同**；
但两模式的 **终局结算不同**，因此它们的胜负率不再相同（初版因两模式结算相同而逐格一致）。
这恰好证明模式开关只改变了 4 个读取计分的策略（平衡、归元冲刺、激进压制、保守自保）的**决策**，
而结算开关改变的是**回合上限局的胜负判定**。

## 结论

### 1. 激进压制的严格占优：**计分造成，不是盘面造成**

- **计分轴开启时，激进压制对全部六个策略严格占优**（57.80%–80.85%）。
- **完全剥离计分后（AI 不读计分 + 终局按盘面进度结算），它只赢两个**：
  对归元冲刺 52.55%、对纯推进 52.94%；对平衡 36.60%、对保守自保 37.24%、
  对纯压制 45.84%、对剥离计分 36.60%——全部低于 50%。
- **裁定：计分。** 初版「盘面造成」的结论建立在一个未完全隔离的测量上（终局仍用计分结算）。
  修正后，盘面本身**不**让压制占优；压制优势来自 AI 对计分的读取与回合上限的计分结算。
- **推论：单靠调计分/结算规则就有修复空间。** 这与初版结论相反；初版据此否决了「修计分」路线，
  该否决理由（工单 09 结论 5）已被本次修正推翻。ADR 0011 已同步修订。

### 2. 盘面本身偏好推进，不是压制

- board-only 下占优最多的是 `平衡` 与 `剥离计分`（各 5/6），即**同时推进并适度压制**的策略；
  纯推进（只推进不压制）只赢 0/6（被压制型与平衡型压制）。
- 纯压制（只压制不推进）在 board-only 下 3/6：能赢归元冲刺、激进压制、纯推进，
  但输给平衡、保守自保、剥离计分。
- **机制**：`actionsToGuiYuan` 衡量的是**自己距五行归元**。一次推进使自己 -1，一次压制使对手 +1，
  在赛跑上等价；但压制会在对手盘面进入加持 2 / 全道损后出现 0 收益（ticket 08 的软拐点/硬封顶），
  而推进直到归元前稳定 -1。因此纯压制在盘面进度上不稳定，长期不如推进。

### 3. 高流局率仍来自盘面节奏，但压制型先手优势不是纯盘面现象

- 全部无序对的平均流局率：scoring **37.19%** → board-only **44.65%**（不降反升）。
  高流局率是压制把对局拖入 30 回合上限的盘面结果，这一点与初版一致。
- 压制型对局在两种模式下都接近满流局：`激进压制 vs 纯压制` 99.33% → 99.72%。
- board-only 的真实平局率 `trueDrawRate` 为 **12.64%**（盘面进度与归一节点数都相同），
  这是本次新增的「终局按盘面结算」的直接产物。
- 全部无序对的平均先手胜率：scoring **54.15%** → board-only **45.25%**。
  board-only 下先手胜率整体低于 50%，是「盘面结算 + 平局判 DRAW」的产物，不再是压制型专属。
  逐策略「先手胜率 − 后手胜率」（座次优势，按有序对平均）：

  | 策略 | scoring | board-only |
  | --- | ---: | ---: |
  | 平衡 | +7.97pp | +5.18pp |
  | 归元冲刺 | +3.47pp | +3.43pp |
  | 激进压制 | +13.59pp | +0.15pp |
  | 保守自保 | +4.68pp | +5.04pp |
  | 纯推进 | +4.82pp | +3.43pp |
  | 纯压制 | +14.41pp | −0.42pp |
  | 剥离计分 | +9.13pp | +5.18pp |

  压制型（激进压制、纯压制）在计分模式下的高座次优势（+13.59pp / +14.41pp）在 board-only 下**消失**
  （+0.15pp / −0.42pp）。**裁定：压制型先手优势来自计分结算，不是纯盘面现象。**
  高流局率本身是盘面节奏，但「压制型先手优势」是计分放大的结果。

### 4. 一句话回答工单四问

1. 用同一策略族、同一 `seed=10000`、每座次 2000 局重跑完整对拼矩阵：完成（见上）。
2. 与现状逐格对照：**18 个有序格（9 个无序对）强弱关系翻转**，清单见「强弱关系翻转」。
3. 激进压制的严格占优：**计分造成**。完全剥离计分后它只赢 2/6，无任一策略严格占优。
4. 高流局率：**盘面节奏**（关闭计分后更高）；压制型先手优势：**计分造成**（关闭计分后消失）。
5. 盘面本身就让压制占优：**否**。盘面偏好推进（平衡/剥离计分 5/6）。因此调计分/结算规则是可行杠杆。

## 发现的口径缺陷（工单 09 已修复）

Ticket 06 的 `HeadToHeadMatchup.drawRate` 把「平局率」（`winner === 'DRAW'`，本项目恒为 0）当作流局率输出，
与 `Metrics.ts` 的唯一口径（`drawRate` 别名 `maxRoundsRate`，回合上限结算率）冲突，导致对拼报告的
「流局率」恒显示 0.00%。工单 09 已修复：`drawRate` 改回流局率，另设 `trueDrawRate` 表示平局率；
`seatBalancedWinRate` 公式（胜场 + 0.5 × 平局）数值不变，因为真实平局恒为 0。
本次修正后 board-only 的真实平局率不再为 0（12.64%），该公式正确地把平局计为半场。
回归测试锁定：`对拼矩阵的 drawRate 是流局率（= 1 - 归元率），不是平局率`。

## 解释边界

- `board-only` 关闭 **AI 对规则得分的读取**（`RuleSwitches.isBoardOnly`）**且**把回合上限结算
  改为**盘面进度判定**（`MatchOptions.isBoardSettlement`），不改动作合法性、状态转移或五行归元胜负。
- 盘面结算的三级口径（`actionsToGuiYuan` → `guiYiNodes` → `DRAW`）是**测量选择**，不是游戏规则；
  默认路径（`isBoardSettlement: false`）逐字节不变，生产规则未改。
- 「另一种盘面结算（残留道损少者胜）会保留初版结论」这一敏感性已在上文记录；
  读者应知道结论依赖于「盘面价值 = 距五行归元的距离」这一口径。
- 本报告是**测量**，不是改动建议。是否调整结算规则/计分/盘面，由后续规则工单决定。

# 先手归元终轮采用天命揭牌与听牌收紧至差一侧

## 背景与问题

在原有规则与状态机设计中，先手（P1）达成五行归元后，若后手（P2）未点亮侧数 ≤ 2，会给予后手一个完整的常规行动半回合（包含可能触发的爆发连动）作为追平机会。然而在实际交互体验与数学逻辑中，当先手已经达成锁定归元时，后手若仍处于包含 5 个常规按钮、甚至能发动无效攻击或多次连动的常规回合，会导致对局终局交互极其怪异、节奏冗长且体验割裂。

经研讨，我们决定将后手追平流程重塑为**终轮天命揭牌 (Showdown Draw)**，并将听牌临界态收紧为**严格差一侧 (Unlighted = 1)**。

## 决定

1. **废除后手追平常规行动流，改用终轮天命揭牌 (Showdown Draw)。** 先手达成归元时：后手未听牌即常规秒结；后手听牌则跳过后手常规行动，由系统直接揭晓一张天干判定胜负——能补全最后一侧则后手反败为胜，否则先手获胜。
2. **听牌临界态阈值收紧至严格差 1 侧**（`countUnlightedSides === 1`）。盘面差 2 侧时单抽在数学上不可能当场归元，归入未听牌秒结。
3. **先后手与轮次模型固化。** 大回合固定由先手半回合与后手半回合依序闭合；爆发属于半回合内的战术连动，不改变大回合结构及顺位。

规则机制归 `docs/GDD.md` §2.1，术语归 `GLOSSARY.md`，本节不复述。

## 被否决的方案

- **保留后手完整操作回合并允许连动**：
  - 否决原因：对手已然归元，后手发动破/强破等攻击扣分毫无意义；允许后手继续连动会让终局状态机分支极度复杂，且让玩家陷入迷茫与冗长的无意义思考。
- **纯后台直接弹窗结算，不展示抽牌过程**：
  - 否决原因：完全跳过抽卡会削弱终局的高潮情绪价值，失去“绝杀神抽/后发制人”的戏剧张力。
- **听牌阈值保留 ≤ 2 侧**：
  - 否决原因：单抽在数学上绝对无法填补 2 个未点亮侧，保留 ≤ 2 必须重新引入复杂连动，与去繁就简的设计目标相悖。

## 后果

1. 领域模型与 `GLOSSARY.md` 已同步更新。
2. 核心状态机 `State.ts`、`ActionResolver.ts`、`TurnManager.ts` 以及前端/小游戏视图流需要依此契约落地实现，后续将通过专门工单实施。
3. 听牌临界态从 `<= 2` 收紧至 `=== 1` 后，先手秒结率将进一步纯净化（未听牌秒结率升至 ~97%+），推演性能与对局紧凑感进一步提升。

## 勘误与实测修订（由 ADR 0009 追加）

本节只修正事实，不改变上述决策本身。

- 上文「后果」第 3 条的 **~97%+** 系当时未经推演验证的估计。
- 10,000 局无头推演（`npm run benchmark:headless`，`balancedStrategy` 自对弈）实测：在**先手先达成归元**的对局中，常规秒结约 **38.6%**、终轮天命揭牌约 **61.4%**；揭牌占全部对局约 **33.3%**。
- 原因：阈值虽已从 `<= 2` 收紧至 `=== 1`（这一步确实把触发面从 92.3% 压到 53.3%），但「后手严格差 1 侧」本身即为高频终局形态，因此该分支并非罕见边界，而是主流终局路径。
- 决策本身（保留揭牌、保留 `=== 1` 阈值）经复核后**维持不变**，理由与被否决的备选方案见 ADR 0009。

# 平衡路线决定：修规则，不修计分也不修 AI

## 背景与问题

本轮审计（spec `balance-audit-and-dominance`）第一次把「游戏能否成立」当成一个问题来回答。此前所有平衡决策都建立在一套不可复跑、口径不明、且缺少关键一问的数字上：测量工具被反复重建又随实验回退，连已经做出的证伪记录都无法复跑。审计先修好工具的可信度（六处已确认的方法缺陷，见「证据 1」），再第一次用**座次平衡的跨策略对拼矩阵**问出关键一问。

答案是否定的：现状下**激进压制对全部其它六个策略严格占优**，而压制型自对弈同时表现为九成以上的流局率与六成以上的先手胜率——即**个体最优、集体无聊**。项目负责人已确认，此方向不处理则后续工作无法推进。

工单 11 的任务是：记录审计发现的全部方法缺陷及其修复情况、给出「是否存在严格占优路线」的最终判定、在**修规则 / 修计分 / 修 AI / 维持现状**四条路线中选择一条并说明理由、列出被否决的备选方案。

本 ADR 只做决定与记录，**不实施任何规则改动**：spec 的 Out of Scope 明确「本 spec 只造工具，不改规则」。被选路线的落地工单由「后果」节点名。

### 2. 「是否存在严格占优路线」的最终判定：**是**

**判定依据只有一处：座次平衡的跨策略对拼矩阵（工单 09，`docs/headless/board-value-without-scoring.md`）。** 自对弈归元率不能回答此问（缺陷 1）。

计分轴开启（生产现状）下，激进压制对全部其它六个策略的座次平衡胜率：

| 对手 | 平衡 | 归元冲刺 | 保守自保 | 纯推进 | 纯压制 | 剥离计分 |
| --- | ---: | ---: | ---: | ---: | ---: | ---: |
| 激进压制胜率 | 57.80% | 79.27% | 71.88% | 78.77% | 80.85% | 78.60% |

计分轴关闭（`boardOnly`，AI 只按盘面判优）后，激进压制对同一组六个策略为 **79.53%–82.93%**（对平衡 80.20%）。**两个模式下它都严格占优，且关闭计分后更强、更均匀。**

**裁定：严格占优存在，且由盘面造成，不是计分造成。** 对照自检：纯推进 / 纯压制 / 剥离计分的 `scoreDeltaWeight` 本来为 0，两模式下决策逐字节相同，它们两两之间的格子完全一致——差异只来自 4 个读取计分的策略。计分只改变部分差距的**幅度**（尤其对平衡），不改变**方向**。

同一矩阵还裁定：**高流局率与压制型的先手优势同样来自盘面，不来自计分。** 全部无序对的平均流局率 scoring 37.19% → board-only 44.65%（不降反升）；平均先手胜率 54.15% → 56.25%；激进压制 vs 纯压制流局率 99.33% → 99.72%。「个体最优、集体无聊」是同一现象的四面：严格占优、高流局、先手偏置，都来自盘面节奏。

### 3. 为什么不是计分、也不是 AI

**计分不是杠杆。** 若盘面本身就让压制占优，则单靠调计分无法修复（工单 09 结论 5）。ADR 0010 的计分杠杆实验也独立印证：能恢复变体 B 归元率的两条候选（撤销攻击强化、攻击净收益归零）都把另一模式推到 ≈99.9%、令纯竞速成为单一解、使护栏失效；道损惩罚下调则与现状逐格相同（缺陷 3 的死参数）。

**AI 也不是杠杆。** 工单 10（`docs/headless/dynamic-switching-policy.md`）第一次用动态策略检验「按盘面在推进与压制之间切换」的设计意图：主策略在计分模式下 7 格全部 > 50%，但对最强预设激进压制只赢 **+0.71pp**（30,000 局合并 50.71%，95% CI [50.14%, 51.28%]），单次 2000 局与 0 无法区分；在盘面模式下主策略 **49.90%**，不能全胜。对照策略「从不切换」恒为 50.00%（与激进压制逐字节相同），因此切换本身的净收益约 +0.7pp，量级只有 1pp。设计意图**只弱成立**：唯一有效的信号是工单 08 的软拐点「打加持 2 收益 0」，而「我更快归一就切换」这一半没有独立价值。搜索并非穷尽，但可改进方向的收益空间已被压缩到 1pp 量级——杠杆不在 AI。

**盘面才是杠杆。** 工单 08（`docs/headless/atk-marginal-return.md`）给出机制：一次【破】的盘面边际收益是**逐侧阶跃函数**——命中 `0` 或 `1` 记 +1，首次命中加持 `2` 记 0，命中已道损记 0；从全虚空盘面出发的前 10 次【破】边际收益**全部是 +1，不存在递减**，唯一硬封顶（对手全道损）在真实对局中几乎不出现。即**压制在盘面上全程不亏、没有自我限制**，最优解必然是尽量多压制，「根据盘面切换」没有存在空间。这正是「把【破】提前到低位态后游戏立刻崩坏」（ADR 0010）的**必要前置**；计分只是放大器。

## 决策

1. **路线 = 修规则。** 通过盘面 / 动作 / 回合上限结算层面的规则改动，让**持续压制出现真实、可达的边际代价或反噬**（即让压制在某个可达盘面区域不再严格 +1 不亏），从而给「在推进与压制之间切换」留出存在空间。具体机制与数值由后续规则工单提出，**本 ADR 不预设具体方案**；本 spec 不实施规则改动（Out of Scope）。

   选择修规则的理由全部来自「证据 2–3」：严格占优由盘面造成（09）、压制无递减（08）、动态 AI 收益只有 1pp 量级且盘面模式下失效（10）、计分杠杆已在 09/ADR 0010 两次被证伪。计分与 AI 只能改变差距幅度，不能改变方向。

2. **护栏带处置：两条带都保留，互不代换；启发式带是当前唯一的 live 红线。**
   - ADR 0001 的 **25%–80%** 只在「搜索深度 1/2 自对弈、200 种子、60 次行动机会」口径下有效，当前无 live 断言，作为历史护栏保留。
   - live 测试的 **75%–95%（归元率）与 [0.45, 0.55]（先手胜率）** 是「启发式预设 `balancedStrategy` 自对弈、500 局、`baseSeed=10000`、30 大回合」口径，是当前 `npm test` 实际执行的红线；本 ADR 记录其出处与口径，使其不再「无 ADR」。两条带 AI 口径不同，**禁止互相代入比较**。
   - 强弱对阵 **≥65%** 仍只在搜索深度 1/2 口径下有效，本轮不重建启发式等价护栏。
   - **这些带描述的是规则改动前的现状，不是新游戏的目标值。** 后续规则改动落地后，必须用测量台复跑并按新规则重设护栏（见「后果」）。

3. **死旋钮处置维持工单 05 的建议，本 ADR 不实施。** `DAMAGE_PENALTY`、稀有度整条链、`rules` 转发死参数、「仅终局生效」类参数：接线属于新机制、删除属于清理，均另立工单；本 ADR 只要求文档与它们保持一致（GDD 已在本 ADR 同步）。

## 被否决的备选方案

1. **修计分（调 `PointsConfig` 数值）。** 否决。工单 09 已证：关闭 AI 对计分的读取后激进压制仍对全部六策略严格占优（79.53%–82.93%），计分只影响幅度不影响方向，故单靠调计分无法修复。ADR 0010 的计分杠杆实验进一步显示，能恢复归元率的候选会把另一模式推到 ≈99.9% 并击穿护栏，等于用一个更严重的失衡替换另一个。

2. **修 AI（把动态切换做成生产策略）。** 否决。工单 10 实测：动态策略对最强预设激进压制只赢 +0.71pp（95% CI [50.14%, 51.28%]），盘面模式下 49.90% 反而不能全胜；「从不切换」对照恒为 50.00%。设计意图只弱成立，可用信号只剩「打加持侧是空枪」一条，收益空间 1pp 量级。AI 侧无法解决盘面无递减这一根因。

3. **维持现状。** 否决。现状即「个体最优、集体无聊」：激进压制严格占优，压制型自对弈流局率 >90%、先手胜率 >60%。项目负责人已确认此方向不处理则后续工作无法推进；护栏虽仍绿，但那是自对弈归元率护栏，本就不检测占优（缺陷 1）。

4. **给低位态加选项（变体 B）来制造决策空间。** 否决。ADR 0010 已用两轮杠杆实验证伪：它把【破】提前到 0/-1 阶段，与 2.5 倍攻击状态分叠加后使压制轴净收益过高，平衡归元率跌至 21.18%，对局被拖入 30 回合分数结算。

5. **保留变体 B 开关但默认关闭 / 保留死旋钮「以备后用」。** 否决。一个被证伪、且需要推翻 ADR 0002 才能成立的规则分支，或一个 AI 与终局都不读的死参数，留着只会成为「未接线的旋钮」，诱导后续实验白跑一整格（工单 05 的一般化结论）。

## 后果

1. **后续工作（本 spec 范围之外，须另立规则工单）：** 提出并验证让持续压制出现真实边际代价/反噬的盘面或规则改动。该工单必须：
   - 用座次平衡对拼矩阵检验改动后是否仍有策略严格占优（陷阱 B 守卫强制附带矩阵）；
   - 流局率与先后手胜率成对报告（陷阱 C）；
   - 改动前后逐格对照，并说明哪些强弱关系被翻转；
   - 复跑并重设全部护栏带（现有带只描述改动前现状）。

2. **护栏与文档不再有未决项。** `docs/headless/guardrail-provenance.md` 中「交工单 11」的四项（权威带、强弱对阵、先手胜率带 ADR 化、测量台断言恢复）由本 ADR 与工单 01–10 的落地一并结清；GDD §2.1 的稀有度加成已注明未接线。

3. **测量台与实验命令为永久基础设施，不随结论回退。** spec 政策 22/23 继续有效；`npm run benchmark:*` 命令与 `src/core/headless/*` 的测量模块、以及全部口径陷阱回归测试长期保留。

4. **生产规则、计分数值与游戏行为本 ADR 一律不改。** 本 ADR 是结论与路线记录；在本 ADR 与后续规则工单落地前，游戏现状不变。

5. **下次有人问「这个值能不能调」时有据可依：** 先查工单 05 的活/死参数清单；「仅终局生效」类参数对 AI 不可见；自对弈归元率不能回答占优；任何占优结论必须附对拼矩阵。

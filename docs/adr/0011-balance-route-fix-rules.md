# 平衡路线决定：修计分，不修盘面也不修 AI

## 背景与问题

本轮审计（spec `balance-audit-and-dominance`）第一次把「游戏能否成立」当成一个问题来回答。此前所有平衡决策都建立在一套不可复跑、口径不明、且缺少关键一问的数字上。审计先修好工具的可信度（九处已确认的方法缺陷，逐条归宿见下表），再用**座次平衡的跨策略对拼矩阵**第一次问出关键一问。

| 审计发现的缺陷 | 归宿 |
| --- | --- |
| 自对弈归元率被当作策略占优的证据 | `docs/headless/metric-definitions.md` 陷阱 B |
| 计分配置注入只到达解析器一侧，未到达 AI 估值器 | `docs/headless/knob-census.md`「活路径」 |
| `DAMAGE_PENALTY` 对 AI 估值不可见 | `docs/headless/knob-census.md` §5 |
| 压制度量曾按「未点亮侧数」统计，得出相反结论 | `docs/headless/metric-definitions.md` §2 |
| 两条互相矛盾且不可比较的护栏带 | `docs/headless/guardrail-provenance.md` C1–C3 |
| 文档回合单位歧义（历史「60 回合」被误读为 120 次行动机会） | ADR 0001 / ADR 0002「术语说明」 |
| `drawRate` 把平局率当流局率输出 | `docs/headless/metric-definitions.md` |
| 多处 `rules` 只转发到候选接缝，接缝从不读它 | `docs/headless/knob-census.md` |
| GDD §2.1 的稀有度加成描述与生产路径不符 | ADR 0002「勘误」 |

答案是否定的：现状下**激进压制对全部其它六个策略严格占优**，而压制型自对弈同时表现为九成以上的流局率与六成以上的先手胜率——即**个体最优、集体无聊**。项目负责人已确认，此方向不处理则后续工作无法推进。

## 决定

1. **路线 = 修计分，不修盘面、不修 AI。** 完全剥离计分（AI 不读计分 **且** 终局改按盘面进度结算）后严格占优消失，说明压制优势来自计分而非盘面；动态策略对激进压制只赢 +0.71pp（95% CI [50.14%, 51.28%]），说明改 AI 也解决不了根因。
   - **已落地的子路线是攻击进度定价。** 攻击状态分按「行动前对手盘面归一节点数」缩放，使压制的相对回报随盘面翻转。机制与设计意图归 `docs/GDD.md` §2.1，取值真源是 `src/core/logic/ScoreCalculator.ts` 的 `POINTS_CONFIG`；搜索过程与被否决候选见 `docs/headless/candidate-search.md`。
   - **终局结算口径未改。** 初版把「终局结算不再按累计分数奖励压制」列为路线的一部分，实际采纳的只是计分重定价子路线：`settlementMode` 仍为 `scoring`，`DAMAGE_PENALTY` 未动。
2. **护栏带的唯一 live 定义在代码里。** `tools/GuardrailBand.ts` 的 `checkGuardrailBand` 是当前生效带的唯一定义，live 测试与候选校验 CLI 都从那里取数。ADR 0001 的 25%–80% 是「搜索深度 1/2 自对弈」口径的历史护栏，两条带**互不代换**。
3. **死旋钮删除，不保留「以备后用」。** 只转发不生效的配置与恒等 0 的字段已删除；`DAMAGE_PENALTY` 仍是「仅终局生效」的活参数（终局读、AI 不读），保留。

## 被否决的方案

1. **只修盘面 / 结算规则、不动计分。** 否决：把终局结算改成纯盘面后，近占优只是从激进压制转移到 `平衡` / `剥离计分`（各 5/6），根因未触及。
2. **修 AI（把动态切换做成生产策略）。** 否决：收益空间被压缩到 1pp 量级，解决不了「计分回报压制」。**限定词不能丢**——设计意图是**在当前计分下**基本不成立，候选规则下尚未检验。
3. **维持现状。** 否决：现状即「个体最优、集体无聊」；护栏虽仍绿，但那是自对弈归元率护栏，本就不检测占优。
4. **给低位态加选项（变体 B）制造决策空间。** 否决：与 2.5 倍攻击状态分叠加后压制轴净收益过高，平衡归元率跌至 21.18%。详见 ADR 0010。
5. **保留死旋钮「以备后用」。** 否决：留着只会诱导后续实验白跑一整格。

## 后果

1. **任何计分改动的复检清单**：座次平衡对拼矩阵（确认没有新策略成为严格占优）、流局率与先后手胜率成对报告、改动前后逐格对照、复跑并重设护栏带。占优结论必须附矩阵。
2. **测量台是永久基础设施。** `npm run benchmark:*` 与 `tools/*` 的测量模块、口径陷阱回归测试长期保留，不随结论回退。
3. **下次有人问「这个值能不能调」时**：先查活/死参数清单（`docs/headless/knob-census.md` §5）；「仅终局生效」类参数对 AI 不可见，调它必然得出「无影响」；自对弈归元率不能回答占优。

## 结论的边界

- **口径依赖**：「占优由计分造成」只在**盘面价值 = 距五行归元**（`actionsToGuiYuan`）这一口径下成立。若把终局结算改为「残留道损少者胜」（只保留 `DAMAGE_PENALTY`、其余计分清零），激进压制仍对全部六个对手占优（52.45%–64.00%，对剥离计分 50.15% 临界）。反例见 `docs/headless/board-value-without-scoring.md`「敏感性」一节。
- **适用范围**：结论覆盖**已测的启发式策略集合**（六个固定权重预设 + 一个动态策略），不是对全部策略空间的断言。
- **board-only 的边界**：盘面本身偏好推进（`平衡` / `剥离计分` 各 5/6），所以「压制强」不是盘面事实；但单换结算规则不够，只是把近占优转移走。同一矩阵还裁定：高流局率来自盘面节奏（scoring 37.19% → board-only 44.65%，不降反升），而压制型的先手优势来自计分结算（激进压制 +13.59pp → +0.15pp，纯压制 +14.41pp → −0.42pp）。

## 沿革

初版标题为「修规则，不修计分也不修 AI」，裁定「盘面造成占优」。工单 09 的修正版把终局结算也改为盘面进度判定后重跑，结论翻转，路线随之修订——初版依据的矩阵并未真正剥离计分（回合上限仍按 `POINTS_CONFIG` 结算，约占 44% 的对局）。后续追加的采纳记录与勘误已按分工拆分：机制与意图回写 GDD，护栏与绊线归代码与测试，证据与候选搜索归 `docs/headless/`。

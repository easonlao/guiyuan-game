# 平衡重调：抬高【化】的行为分，收口双级爆发后的先手优势与占优重排

burst-plus-two（ADR 0016：强化/强破恢复双级作用、满溢则亏、门槛放开）落地后，平衡护栏的先手胜率
破了带，占优格局也重新翻转。本 ADR 记录这次平衡重调的决策、理由与被否决的方案；**完整测量
表与复跑口径**的原报告已删（见 git 历史），本文只引关键数字，**取值真源**是
`src/core/logic/ScoreCalculator.ts` 的 `POINTS_CONFIG`。

## 背景与问题

ADR 0016 落地时，同口径实测先手胜率 **54.4%**（带上界 51.0%），且「激进压制」重新对全部六个
对手严格占优。工单 05 的复核对比了规则改动前后（`1b58360` 与 `eca971d`）的终局形态分布：

- **同轮双归元**（后手胜）从 10.0% 压到 4.0%，**常规秒结**（先手胜）从 22.8% 升到 33.0%。

成因是**双级强化让先手更容易「秒结」**：先手用一次强化把最后一格从「差 2 级」直接推到五行归元，
而后手还没到听牌（未点亮侧数 ≠ 1），本应走「终轮天命揭牌」的对局被压缩成先手当场获胜。
也就是说，这不是先手多抽了天牌，而是规则改动改变了节奏的对称性。

## 决定

1. **抬高【化】的行为分：`POINTS_CONFIG.ACTION.TRANS` 30 → 160。**
   双级爆发让【强化】单次作用两级并附带连动，【化】（唯一安全的单级相生建设）相对贬值，
   AI 取舍整体偏向爆发、节奏加快，先手优势随之放大。抬高【化】把节奏拉回。
2. **护栏带的带值不动，只按重调后实测重录锚点注释。** 归元率 `[0.89, 0.95]`、先手胜率
   `[0.47, 0.51]`、堆增量 `< 15MB` 三组界保持不变；锚点从 90.20% / 54.40% 重录为
   92.00% / 49.20%（回退值 75.80% / 58.60%），四个界仍把回退挡在带外。
3. **只修计分，不修规则、不修 AI。** 与 ADR 0011 的路线一致；本决策只动一个计分常量。

## 被否决的方案

1. **只降爆发行为分（`ACTION.BURST` / `BURST_ATK`）。** 实测归元率跌破带（`BURST=50` 时 0.882），
   且 ADR 0002 已明确否决「直接修改爆发基础行为分」——动作基础分涉及单次决策的心理预期。
2. **给「满溢则亏那一级」计分。** 五档扣分扫描（0/100/200/300/400）对先手胜率与归元率几乎无影响：
   该级只出现在近满盘爆发，AI 取舍主要由连动与盘面收益决定。否决。
3. **只降 `BALANCED_WEIGHTS.burstExtraTurn`。** 单独不足以把先手拉回带内，且归元率贴近下界。否决。
4. **只降攻击进度定价的 `span`。** 压低先手的同时把归元率推向或推破上界（`span=0.45` 时归元率 0.956），
   两个指标不能同时带内。否决。
5. **改激进/平衡的 AI 权重。** 或破坏护栏，或对占优无感；ADR 0011 已定「修计分，不修 AI」。否决。

## 后果

- **护栏三条在带定义口径（500 局、种子 10000）下全绿**：归元率 0.920、先手胜率 0.492、堆增量远低于上界。
- **严格占优消失**：`平衡 对 激进压制` 从 40.2% 回到 54.0%，`dominance-regression-guard` 的
  两格钉值与 `experiment-runner` 基线钉值按实测重录。
- **`candidate-validation` 的「标准 1 独立失败」样本改为反向样本（`TRANS: 0`）**：重调后
  「关闭进度定价」不再造出严格占优，故换用本决策的反向样本。
- **已知局限**：护栏带只在种子 10000 的 500 局口径下定义，而先手胜率的标准误约 2.2pp、带宽仅 4pp。
  跨 8 种子复测，重调把均值从 0.539 拉到 0.527，但个别种子仍越带；旧基线自身也有同样问题。
  这是带的固有局限（带宽 < 噪声），是否扩大护栏样本量或加宽带留给后续决定；证据见报告 §7.4。

# ADR 0009: 终轮天命揭牌频率实测修正与机制保留

## 背景与问题

ADR 0007 将先手归元后的后手追平流程重塑为「终轮天命揭牌」，并把听牌临界态收紧至严格差 1 侧。该决策建立在两个**当时未经推演验证**的频率估计之上：

- `GDD.md` §2.1 称常规秒结占 ~93%、终轮追平占 ~7%；
- ADR 0007「后果」第 3 条预测收紧阈值后「未听牌秒结率升至 ~97%+」。

两个数字互相矛盾，且都没有测试或推演记录支撑。现有护栏测试（`ai-evaluator-benchmark-guardrails`）只断言胜率与归元率区间，**未覆盖终局形态分布**，因此该分歧长期未被发现。

## 证据

10,000 局无头推演（`npm run benchmark:headless`，`balancedStrategy` 自对弈）：

| 指标 | 实测 |
| --- | --- |
| 五行归元 | 88.73% |
| 达到回合上限 | 11.27% |
| — 常规秒结 (Sudden) | 20.96% |
| — 追平失败 (Catchup Fail) | 24.60% |
| — 同轮双归元 (Double) | 8.72% |
| — 后手直接归元 (P2 Direct) | 34.45% |
| **天命揭牌合计** | **33.32%** |
| 先手胜 / 后手胜 | 52.44% / 47.56% |
| 平均回合数 | 20.21 |

独立复核（3 个种子 × 3,000 局，直接读 `MatchResult.finalState` 自行计数，不依赖评测器计数器）结果一致，并给出原因分布——**先手锁定归元时，后手剩余未点亮侧数**：

| 后手剩余未点亮侧 | 占比 |
| --- | --- |
| 差 1 侧（触发揭牌） | 53.3% |
| 差 2 侧 | 39.0% |
| 差 3 侧以上 | 8.6% |

据此换算：在先手先达成归元的对局中，常规秒结约 **38.6%**、终轮天命揭牌约 **61.4%**。原文 ~93% / ~97% 与实测不符。

## 决策

1. **保留终轮天命揭牌机制与 `=== 1` 听牌阈值不变。** 先手归元一旦锁定即不可撤销，揭牌是后手在该局面下唯一的翻盘路径；实测揭牌为后手贡献约 9.4% 的全局胜率，是平衡的重要组成。
2. **以实测值修正文档。** `GDD.md` §2.1 与 ADR 0007「后果」第 3 条改为实测频率，并注明数据来源与口径。
3. **将「先手归元时后手差 1 侧占 53.3%」列为待验证的下游假设。** 该比例是终局高频揭牌的直接原因；假设其为「强制自动回合占比过高 → 双方盘面同步推进」的下游症状，交由决策密度实验验证。该实验须把「揭牌率」与「差 1 侧占比」作为对照指标：**若降低强制自动回合后二者不下降，则本假设被证伪。**
4. **本轮不改动揭牌机制本身。** 与之相关的可读性缺口（玩家无法提前看见归一进度与听牌临界态）作为独立议题处理，不混入本轮规则实验。

## 被否决的备选方案

1. **移除揭牌，先手归元即终局**：否决。后手胜率将从 49.2% 降至约 39.8%，先后手平衡崩坏。
2. **恢复 GDD 原版「≤2 侧即给后手完整行动回合」**：否决。实测先手归元时后手差 ≤2 侧占 92.3%，该分支会退化为常态而非边界；且与 ADR 0007 的去繁就简目标相悖。
3. **改为「让后手真的走完那一回合」（概率等价、恢复能动性）**：本轮不采纳，保留为备选。ADR 0007 否决它的主要理由是「允许连动会让终局状态机分支极度复杂」——该理由针对的是 `≤2` 阈值版本；在 `=== 1` 阈值下后手只有一个目标，分支是收敛的，理由已不充分。暂缓原因：本轮优先处理决策密度，避免同时改动两个变量导致无法归因。

## 后果

1. 文档与实测对齐，后续决策不再基于错误的频率前提。
2. **不改变任何游戏规则与数值**：揭牌机制、听牌阈值、计分、胜负判定全部保持原状。
3. 「天命揭牌率」与「先手归元时后手差 1 侧占比」正式成为后续规则实验的对照指标，用于验证或证伪「同步推进」假设。

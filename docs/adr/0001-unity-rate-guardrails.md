# 五行归元率只设护栏，不设目标值

第一阶段体检（`reports/balance-diagnostics/phase1/`）显示五行归元率随回合上限单调上升，且受对局双方防守能力影响：60 回合下规则式对抗为 61%，双方水平相当的搜索自对弈为 44.8%–55.5%，强弱对阵升至 82%。现有电脑只能看两步，真实对局中双方都会阻止对方五行归元，这个比例会降到多少目前测不出来，因此现在定精确目标值没有依据。我们决定只设**护栏**，作为第二阶段调整计分时“不能破坏什么”的判断标准，并约定在什么条件下重新评估。

## 决定

- **回合上限维持 60。** 回合设计不变。
- **强制吸纳暂不处理。** 60 回合下每局约 27–30 次真实决策，已经够用。
- **计分的定位：** 在双方互相限制五行归元的前提下，计分是另一条博弈路线，不只是兜底。
- **护栏**（60 回合、200 种子、交换先手；以下“同水平对局”指搜索深度1/2 自对弈三组）：
  1. 同水平对局的五行归元率保持在 **25%–80%**。当前为 44.8%–55.5%。
  2. 强弱对阵中强方胜率**不低于 65%**，保证计分仍然奖励技术。当前为 70.0%–71.3%。
  3. 同水平对局中，先手胜率的 95% 置信区间**不能比当前更偏离 50%**。当前：深度1偏分数权重为 54.3% [49.4%, 59.1%]，深度1偏点亮权重为 58.0% [53.2%, 62.8%]，深度2偏分数权重为 54.3% [49.4%, 59.1%]。
- **重新评估触发条件：** 做出了视野超过两步的防守型电脑，能测到五行归元率的真实下限；或者加入了扩展内容，改变了节点、动作或胜负条件。

## 被否决的方案

- **定一个目标值（例如 50%–70%）。** 否决原因：现有数据来自防守能力有限的电脑，目标值会随电脑强度漂移，第二阶段会去追一个不可靠的数字。
- **暂不写 ADR，等更强的电脑做出来再说。** 否决原因：第二阶段马上要比较计分方案，需要现在就有判断标准。
- **不设五行归元率护栏，只看计分自身的指标。** 否决原因：计分方案可能通过改变电脑的取舍间接把五行归元挤成摆设，或者让计分失去作用。

## 后果

第二阶段的计分问题按下面的顺序处理：先做只测量、不改规则的诊断，验证“计分和五行归元进度高度重合”这一假设（`POINTS_CONFIG` 中建设类得分明显高于攻击类，但还没有数据）；之后的实验再放大压制类得分，同时观察逆转率（当前 22%–25%）和先手胜率。每个方案都必须满足上面三条护栏。

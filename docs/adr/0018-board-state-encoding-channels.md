# 法盘状态编码：元素色表身份、等级走亮度阶梯、节点级状态与候选标记各占独立通道

表现层的等级原来由色相承载——工单 08 定的规则是「1 五行色、2 同一五行色发光」，虚空 (0) 与道损 (-1) 都用暗底。新一轮画面复查暴露三处误读：盘下图例的四个等级样例**全部用木色画**（`src/minigame/game-scene.ts:858-862` 把 `WuXing.WOOD` 写死传入），玩家于是把「绿」读成「点亮」；虚空与道损同为暗底（`src/minigame/views/board-view.ts:536`），在对方环约 20px 半径的半鱼上分不出来；归一与亢极在盘上没有任何标记——`isGuiYi` 只被拿去数「你 x/5」（`board-view.ts:488`），`isKangJi` 投影出来后无人读（`board-view.ts:287`、`:361`）。根因是同一根色相通道被身份与等级同时征用。

**决定**：把标记分成三层，每层占一条互不重叠的通道。

1. **每一侧（鱼半身）**：色相恒表**五行身份**，任何等级都保留自己的元素色；等级只走**亮度阶梯**——虚空 = 空心（只留元素色淡描边）、点亮 = 元素色实心、加持 = 实心 + 光晕、道损 = 暗化的元素色 + 裂纹。
2. **节点（主印外侧）**：归一 = 一圈金环；亢极 = 双层金环。中性表达「多一层就是更满」，不用警示色、不用脉动。
3. **候选与预览（半环外沿）**：会变的那一侧外侧挂一段元素色弧；决策期**同相位慢呼吸**（所有候选共用一个节拍），按住按钮时该弧加快，并叠加路径箭头（化 = 内环顺时针弧箭、破 = 径向箭）与目标侧的下一步幽灵态。

同时拍死三处取舍：**虚空用空心而不是暗底**（空心与实心在约 12px 宽的半鱼上仍然可分，两个暗底不能）；**决策期不做逐节点闪动**（归一局面最多 3 个候选、2 个不同落点，各自闪就是工单 08 想消除的信息混杂）；**对手盘不再整体变暗**（在新通道里「暗」已经等于虚空，再调暗对手会让它的虚空与点亮分不出来，归属改由环带的实线/虚线加「你 / 天道」标签承担）。

## Considered Options

- **维持工单 08 的「色相 = 等级」，只把图例改成「以木为例」**：治不了根。只要「有没有色」等于「点不点亮」，玩家就得先解码颜色才知道状态，换到火 / 土 / 金 / 水节点时图例与盘面依然对不上。
- **给每一侧常驻小点数或数字**：读数最准，但在对方环约 12px 宽的半鱼上挤成一团，反而增加噪声。改为按住预览时才显示准确读数。
- **亢极用警示色或脉动**：亢极确实会强制散气，但它同时满足归一门槛、也是强化的合法源，染红会让玩家把最高进度读成坏状态。**未采纳**，改用「金环多一层」。
- **保持对手盘整体变暗以区分主次**：归属其实已由环带的实线/虚线与「你 / 天道」标签说清，主印大小不必再兼这一份差事；而变暗会直接撞坏新的等级通道。**未采纳**。

## Consequences

- 工单 08 的「1 五行色、2 同一五行色发光」作废；盘下图例与上一招变化条的文案统一到 `GLOSSARY.md` 正名「道损 / 虚空 / 点亮 / 加持」（`崩坏`、`发光` 已列入该表的 _Avoid_）。
- 撤掉对手盘的整体暗化后，外环主印需要放大到接近内环；`BoardView.resize` 的主印不重叠保证（`board-view.ts:187`）要一并把归一环的外扩算进去。像素取值归 `docs/HLD.md` §2 Layer 3 与代码常量，本 ADR 只记编码约定。
- 候选弧与路径箭头不需要新管道：`resolveActionPath` / `setActivePaths` / `BoardConnectionView.isActive` 都还在，只是 `renderSelf` 不再画它们（`board-view.ts:367-372`）。但**强化与强破的目标侧不在载荷里**（解析时逐次重读盘面、各自按阴侧优先决定），它们的预览必须真跑一遍解析器，不能沿用现有兜底的近似落点。
- 图例只剩「亮度 ↔ 等级」一件事要教：五个节点在任何等级都带自己的元素色描边，图例不必再教「颜色 ↔ 元素」。

## 勘误：节点级标记改为「环 + 流动 + 元素外溢」（票 02 落地时追加）

本节只记录现状，不改变上文的分层结构；但「亢极 = 双层金环」与对「脉动」的一刀切已被取代。

- **归一 = 一圈金环 + 沿环缓慢流动的金色高光**（4.5s 一圈、长尾渐隐）：只要节点归一就有，与是否亢极无关。
- **亢极 = 归一那一层之上再叠元素色柔光**（取该节点的五行色）+ **一圈外扩涟漪**（比归一更慢更淡）——表达「满溢 / 泄露 / 不稳」。
- 因此上文「决定 2」的「亢极 = 双层金环」「多一层就是更满」作废；「不用脉动」放宽为**不用警示色**：节点级状态现在带运动（金色流动 / 元素色涟漪），但归一用中性金、亢极用节点五行色，均不借用警示色相。当初拒绝脉动是为了不把亢极读成坏状态，这条理由仍成立，故只允许「流动 / 满溢」的运动语义，不允许闪烁或警示色。
- 像素取值（环半径、线宽、流光周期与拖尾、外溢尺度、涟漪周期）以 `src/minigame/views/board-view.ts` 常量为真源；法盘底晕按 `NODE_AURA_OUTSET_RATIO` 放大以容纳元素色外溢，票 05 的 `resize` 避让改用同一个常量（不再是环间距）。

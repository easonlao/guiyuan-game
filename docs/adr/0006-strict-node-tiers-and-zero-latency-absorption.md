# ADR 0006: 严格天道三态分层与低位无感吸纳交互契约

## 状态
Accepted (已接受)

## 背景与问题

在归元弈（Guiyuan）的早期原型与初始实现中，存在以下几处模糊与体验偏差：
1. **低位态交互拖沓**：当抽中天干对应节点处于低位态（虚空 0 或道损 -1）时，虽然动作解析器仅生成唯一合法动作 `AUTO`，但表现层保留了 0.75 秒倒计时和“自动吸纳中”按钮，导致非抉择步骤产生不必要的停顿感；
2. **调息门槛过于宽泛**：此前逻辑判定为 `stemNode[oppositePolarity] < 2`，允许当对侧已达点亮(1)时调息为加持(2)，打破了“调息旨在疗伤救损与基础点亮，高阶加持需通过生克流转”的博弈设计意图；
3. **动作枯竭时的兜底失真**：当对应侧处于中位态（1 或 2），若对侧不可调息且相生相克目标已达极值（(2, 2) 无法化，或 (-1, -1) 无法破），原实现兜底退回到 `AUTO` 吸纳，违背了“达到 1 或 2 后严禁原地直接吸纳”的设计铁律。

## 决策

1. **确立严格“天道三态”流转契约与能量守恒模型**：
   - **能量模型与自身扣减真相**：每回合天干为 1 点外部输入能量。低位态自身吸纳自身+1；中位态调息、化、破将输入能量导向外部，**自身那一侧绝对不扣除等级（保持不变）**。唯有进阶【爆发】（强化/强破）会主动消耗自身对应侧 1 级以换取珍贵的连动额外回合。
   - **低位态（-1 或 0）**：仅允许【吸纳 (AUTO)】，状态 +1。表现层实行**纯自动无感流转**（不显示按钮、不设倒计时、直接飞行动画结算后移交）。
   - **中位态（1 或 2，未达成亢极）**：**严禁原地吸纳**。
     - **调息 (CONVERT)**：严格收窄前置条件，**仅当同节点对侧 <= 0（虚空 0 或道损 -1）时**允许调息；对侧 >= 1 时严禁调息。
     - **化 (TRANS)**：严格限定阴天干。遵循阴干优先原则（阴干未满 2 滋养阴，满 2 后滋养阳）；相生节点已为 (2, 2) 时禁止化。
     - **破 (ATK)**：严格限定阳天干。遵循阴干优先原则（对手阴未至 -1 压制阴，达 -1 后压制阳）；对手相克节点已为 (-1, -1) 时禁止破。
     - **消散过牌 (PASS)**：当无任何合法动作可选时（如生克目标全极值且锁调息/爆发），天干自然消散过牌，直接结束本回合行动，不得回退为原地吸纳。
   - **进阶爆发 (BURST / BURST_ATK)**：必须达成归一，且**严格对齐极性**（阴干发动【强化】消耗阴侧，阳干发动【强破】消耗阳侧）。连动额外回合中严格禁止二次爆发。
   - **极位态（(2, 2) 亢极）**：天道满溢，仅允许强制【亢极散气 (DISSIPATE)】扣除 1 级，不得选择其他任何动作。

2. **表现层与核心逻辑解耦协同**：
   - `ActionCandidates.ts` 纯函数精确输出上述合法动作子集；
   - 表现层（`game-manager.ts` 及场景树）对 `AUTO` 与 `DISSIPATE` 执行直接动画流转，仅在中位态存在多重抉择时唤起交互按钮。

## 被否决的备选方案

1. **方案 A：保留 0.75 秒倒计时吸纳展示**：
   - 否决原因：低位态没有任何策略选择空间，强留倒计时和按钮只会拉长局时、打断对弈节奏。
2. **方案 B：允许对侧为 1 时调息到加持 2**：
   - 否决原因：过度降低了达成“归一”或“加持”的难度，弱化了相生相克的流转博弈。
3. **方案 C：无可用动作时兜底强制吸纳加持自身**：
   - 否决原因：违背了中位态“只能向外调息或生克”的限制，可能导致被动自肥或意外达成不合规则的加持。

## 后果与收益

- **规则边界彻底清晰**：彻底消除了代码实现与 GDD 规范之间的歧义，为 AI 估值器和人类玩家提供高度自洽的博弈模型。
- **对战节奏大幅提速**：前期大量低位吸纳步骤全自动播放，单局时间显著压缩，玩家注意力高度集中在真正的策略抉择回合。
- **高确定性测试基准**：动作候选生成器针对各种盘面边界（全道损、全亢极、连动锁爆发等）具备 100% 确定性的单元测试覆盖。

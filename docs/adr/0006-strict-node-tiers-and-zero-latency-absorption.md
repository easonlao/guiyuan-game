# ADR 0006: 严格天道三态分层与低位无感吸纳交互契约

## 状态
Accepted (已接受)

## 背景与问题

在归元弈（Guiyuan）的早期原型与初始实现中，存在以下几处模糊与体验偏差：
1. **低位态交互拖沓**：当抽中天干对应节点处于低位态（虚空 0 或道损 -1）时，虽然动作解析器仅生成唯一合法动作 `AUTO`，但表现层保留了 0.75 秒倒计时和“自动吸纳中”按钮，导致非抉择步骤产生不必要的停顿感；
2. **调息门槛过于宽泛**：此前逻辑判定为 `stemNode[oppositePolarity] < 2`，允许当对侧已达点亮(1)时调息为加持(2)，打破了“调息旨在疗伤救损与基础点亮，高阶加持需通过生克流转”的博弈设计意图；
3. **动作枯竭时的兜底失真**：当对应侧处于中位态（1 或 2），若对侧不可调息且相生相克目标已达极值（(2, 2) 无法化，或 (-1, -1) 无法破），原实现兜底退回到 `AUTO` 吸纳，违背了“达到 1 或 2 后严禁原地直接吸纳”的设计铁律。

## 决策

1. **确立严格“天道三态”流转契约与能量守恒模型**：低位态仅【吸纳】；中位态严禁原地吸纳，调息门槛收窄至「对侧 ≤ 0」；极位态强制【亢极散气】；爆发必须已归一且连动中禁二次爆发。**规则正文归 `docs/GDD.md` §2.2 / §2.3，本节不复述。**
2. **表现层与核心逻辑解耦协同**：`ActionCandidates` 纯函数输出合法动作子集；表现层对 `AUTO` 与 `DISSIPATE` 直接动画流转，仅在中位态存在多重抉择时唤起交互按钮（交互契约归 `docs/GDD.md` §2.4）。

## 被否决的备选方案

1. **方案 A：保留 0.75 秒倒计时吸纳展示**：
   - 否决原因：低位态没有任何策略选择空间，强留倒计时和按钮只会拉长局时、打断对弈节奏。
2. **方案 B：允许对侧为 1 时调息到加持 2**：
   - 否决原因：过度降低了达成“归一”或“加持”的难度，弱化了相生相克的流转博弈。
3. **方案 C：无可用动作时兜底强制吸纳加持自身**：
   - 否决原因：违背了中位态“只能向外调息或生克”的限制，可能导致被动自肥或意外达成不合规则的加持。

## 后果与收益

- **规则边界彻底清晰**：彻底消除了代码实现与 GDD 规范之间的歧义，为 AI 估值器和人类玩家提供高度自洽的博弈模型。
- **对战节奏大幅提速**：前期大量低位吸纳步骤全自动播放，单局时间显著压缩，玩家注意力高度集中在真正的策略抉择回合。
- **高确定性测试基准**：动作候选生成器针对各种盘面边界（全道损、全亢极、连动锁爆发等）具备 100% 确定性的单元测试覆盖。

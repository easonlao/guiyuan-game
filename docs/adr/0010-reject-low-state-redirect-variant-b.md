# ADR 0010: 否决对称低位改道（变体 B）

## 背景与问题

ADR 0006 确立「严格天道三态」契约后，低位态（虚空 0 / 道损 -1）**仅允许原地【吸纳】**，无任何策略选择。作为对「低位态是死局」这一设计担忧的回应，本实验提出**变体 B**：抽中天干对应侧处于低位态时，阴天干可改道【化】向相生节点、阳天干可改道【破】向相克节点，代价是放弃本次原地 +1；默认关闭（`lowStateRedirect`）。

本 ADR 记录用无头推演台（可注入计分配置）对变体 B 做的两轮杠杆实验，并给出采纳或回退的最终决定。完整数据见 `docs/headless/low-state-redirect-experiment.md`。

## 证据

命令 `npm run benchmark:ai-preference` 与 `npm run benchmark:score-lever`，每格 5000 局、种子基数 10000、30 回合上限；`npm run benchmark:head-to-head` 为 6×5 有序对 × 2000 局并做座次平衡。off 基线复现既有护栏（平衡/off 归元率 88.64%、平均回合 20.20、先手胜率 52.02%），工具忠实。

**1. 变体 B 开启（`full`）在默认计分下使游戏崩坏。**

| 策略 | 归元率 off → full | 回合上限率 off → full | 平均回合 off → full |
| --- | ---: | ---: | ---: |
| 平衡 | 88.64% → **21.18%** | 11.36% → **78.82%** | 20.20 → 29.01 |
| 归元冲刺 | 99.26% → 73.18% | 0.74% → 26.82% | 15.10 → 24.38 |
| 保守自保 | 98.30% → 24.62% | 1.70% → 75.38% | 16.58 → 28.90 |

「竞速归元」被替换为「30 回合分数结算」，归元率远低于任何健康档位。低位态决策分布证实改道并非死代码（平衡策略 59.4% 的低位态决策走改道），即失衡确由新选项引入。

**2. 杠杆一（只调 AI 偏好）不足以修复。** 4 组既有权重预设的 `full` 归元率最好为归元冲刺 73.18%（< 80% 门槛）；唯一 ≥80% 的 `纯推进`（99.00%）是靠把压制轴与计分轴全部置零实现的退化策略，其低位态决策 95.4% 仍走【吸纳】，等于关掉会受影响的轴而非学会共存。判定：AI 偏好杠杆不能把变体 B 拉回健康。

**3. 杠杆二（改规则计分数值）能恢复归元率，但代价更大。**

| 计分配置 | full 平衡归元率 | off 平衡归元率 | 对拼头名 |
| --- | ---: | ---: | --- |
| 现状 | 21.18% | 88.64% | 激进压制（纯极端不占优） |
| 撤销攻击强化 | 85.72% | **99.90%** | 纯推进（对全部对手 >63%） |
| 攻击净收益归零 | 99.78% | 99.88% | 纯推进 |

- `撤销攻击强化`（撤销 ADR 0002 的 2.5 倍攻击状态分）虽把 `full` 平衡归元率拉回 85.72%，却同时把 **`off` 模式**的建设类策略推到 99.9%（现状 88.64%），即回到 ADR 0002 想要修复的「计分路线沦为点亮附庸」状态。
- `道损惩罚下调` 与现状逐格相同，被证伪为「行为零贡献」参数（AI 估值从不读取它）。
- 两个候选改动都会让纯极端 `纯推进` 在 `full` 模式头名（对全部其它策略 >63%），把「攻防双轨抗衡」退化为「纯竞速单一解」。
- 采纳任一改动都会使 `off` 平衡归元率突破 ADR 0001 护栏与 `ai-evaluator-benchmark-guardrails` 的上限（0.95），护栏不再全绿。

## 决策

1. **否决变体 B。** 回退 `lowStateRedirect` 开关及其在 `ActionCandidates` / `TurnManager` / `game-manager` / 无头推演入口的全部接线与测试。低位态行为回到 ADR 0006 的「仅【吸纳】」。
2. **回退全部实验计分改动。** 本实验从未改动生产默认 `POINTS_CONFIG`；一并移除仅为实验存在的计分配置注入、计分杠杆候选、`createScoreBoundStrategy`、测量台与对拼扫描，使工作区相对实验开始前无意外残留。
3. **保留实验数据与结论。** `docs/headless/low-state-redirect-experiment.md` 保留为证伪记录（含命令、种子、样本量、全部对照表）；本 ADR 记录决定。
4. **生产规则、计分数值与文档维持现状。** GDD / GLOSSARY 无需因本决定改动；计分表与实现的分歧由工单 07 单独处理，计分模块死代码由工单 08 单独处理。

## 被否决的备选方案

1. **直接采纳变体 B（默认开启，计分不变）**：否决。`full` 平衡归元率 21.18%，游戏变为 30 回合分数结算，明显失衡。
2. **采纳变体 B + 撤销攻击强化**：否决。它需要一并推翻 ADR 0002，且把 `off` 模式平衡推到 99.9%、令纯竞速成为单一解、使 ADR 0001 护栏失效——用一个更严重的失衡替换另一个。
3. **采纳变体 B + 攻击净收益归零**：否决。同 2，且更彻底地抹平攻击路线。
4. **保留变体 B 开关但维持默认关闭**：否决。一个被证伪、且需要推翻 ADR 0002 才能成立的规则分支，留着只会成为「未接线的旋钮」，误导后续实验。

## 后果

1. **低位态死局问题仍然开放。** 本实验只回答了「变体 B 能否修复它」，答案是不能；如何让低位态具备决策空间，需另立议题，且不得以推翻 ADR 0001/0002 的攻防双轨为前提。
2. **攻击计分（ADR 0002）与低位强制吸纳（ADR 0006）维持不变**，现有攻防双轨平衡与三条护栏保持有效。
3. 后续任何「给低位态加选项」的提案，须先回答本实验暴露的根因：低位改道把【破】提前到 0/-1 阶段，与 2.5 倍攻击状态分叠加后使压制轴净收益过高。提案必须给出与攻击计分共存的方案，而非单轴归零。

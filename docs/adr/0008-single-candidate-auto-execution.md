# ADR 0008: 唯一合法动作的自动流转机制与交互契约

## 状态
Accepted (已接受)

## 背景与问题

在归元弈（Guiyuan）的规则运转中，除显而易见的“低位吸纳 (AUTO)”与“极位散气 (DISSIPATE)”外，由于生克规则与状态门禁的约束，存在多种中位态或进阶动作下系统生成的候选合法动作列表仅剩 1 项（`getAvailableActions().length === 1`）的特殊边界：
1. **连动额外行动中的归一节点**：在发动爆发后的连动回合抽中已归一节点，因对侧已点亮禁止调息，因连动禁令禁止二次爆发，导致阳天干仅剩唯一【破 (ATK)】、阴天干仅剩唯一【化 (TRANS)】；
2. **生克目标单向极值封死**：当对手相克五行全道损 (-1, -1) 或己方相生五行全加持 (2, 2) 时，常规破/化被封死，导致未归一节点仅剩唯一【调息 (CONVERT)】；
3. **已归一节点的单向受阻**：某一侧生克被极值封死且对侧点亮禁调息，导致仅剩唯一【强化 (BURST)】或唯一【强破 (BURST_ATK)】；
4. **全面受阻兜底**：所有生克、调息、爆发均不可行时，仅剩唯一【消散过牌 (PASS)】。

在此前表现层实现中，仅对 `AUTO`、`DISSIPATE` 与 `PASS` 提供了倒计时自动吸纳/流转，而对上述其他单选项情况，界面会呈现一个孤立的手动按钮，强迫玩家进行没有分支选择意义的机械点击，破坏了对局的行云流水体验。

同时，针对“仅剩单一强化/强破时是否需要允许主动 PASS”以及“是否需要在领域模型中为此类状态定义专有名词”产生了设计决策分歧。

## 决策

1. **统一自动流转原则（Zero Redundant Interaction）。** 凡 `getAvailableActions().length === 1` 的局面，表现层统一启动缓冲倒计时后自动执行，并保留玩家点击加速跳过的权利。交互契约（含倒计时时长与播报文本）归 `docs/GDD.md` §2.4。
2. **坚决不引入额外 PASS 选项。** 唯一动作为爆发时不追加 PASS，保持规则闭环。
3. **不为此类状态创造专有术语。** 把它视作状态机的边界集合规模（`|actions| === 1`），`GLOSSARY.md` 不新增条目。

## 被否决的备选方案

1. **备选方案 A：所有中位态动作（破、化、调息、爆发）即便仅剩 1 个也强制玩家手动点击**：
   - 否决原因：当玩家没有任何其他可选分支时，强迫点击单个按钮属于伪决策与机械操作，拖慢对弈节奏。
2. **备选方案 B：当唯一动作为爆发时增加 PASS**：
   - 否决原因：会使原本不可逆的激进局势产生多余的避险出口，弱化对弈的张力与流转因果性。

## 后果与收益

- **交互体验大幅提升**：彻底消除了无意义的单按钮僵直停顿，无论连动还是单向受阻均能行云流水推进；
- **全端一致性保障**：Web 原型、Canvas 小游戏与后续表现层（ADR 0004 / 0005）均以统一的 `|actions| === 1` 条件处理自动流转逻辑；
- **文档与实现统一**：规则与交互契约在 GDD 与表现层完全对齐。

## 勘误：背景第 3 条的单一爆发候选已不再出现（后续修订追加）

本节只记录现状，不改变上述决策本身。

本文「背景与问题」第 3 条（已归一节点的单向受阻，仅剩唯一【强化】或唯一【强破】）在爆发恢复双级作用、门槛放开（ADR 0016）后已不再成立：强化与强破总是同时生成或同时被排除，不再单独成为唯一候选。该情形的当前枚举归 `docs/GDD.md` §2.4；本文的自动流转决策（`|actions| === 1` 统一自动执行、不追加 PASS）不受影响。

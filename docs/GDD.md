# 归元弈 (Guiyuan) - 游戏设计文档 (GDD)

## 1. 游戏概述 (Game Overview)
**游戏名称**：归元弈  
**游戏核心**：一款基于五行相生相克、阴阳流转的轻度策略对弈小游戏。  
**目标受众**：喜欢轻度脑力博弈、对战棋/卡牌对决感兴趣的休闲策略玩家。  
**视听风格**：**卡通修仙风**。结合修仙背景与 Q 版卡通人物，将硬核的五行规则包裹在轻松可爱、易于接受的美术包装中。人物作为对战化身（Avatar），具有强表现力：当玩家打出“化”或“破”时，角色会有对应的施法动作与语音气泡；受到攻击跌入“道损”时会有眩晕/受伤表情，提供丰富的情绪反馈。

---

## 2. 核心玩法 (Core Gameplay)
游戏采用回合制对战，双方在一块包含五行（金、木、水、火、土）十个节点（每个元素独立分阴、阳两条状态轨道，取值范围为 `-1 ~ 2`）的棋盘上进行资源调配与对弈博弈。

### 2.1 游戏目标与回合上限
- **主目标（五行归元与大回合闭合判定）**：
  - **五行归元定义**：己方五个元素节点全部达到“归一”状态（即 5 个元素的阴、阳共 10 个侧均至少点亮至 1 或 2）。五行归元为不可逆的终极里程碑成就，一旦在行动中达成即锁定记录。
  - **胜负判定时点（智能快刀闭合制）**：胜负判定在**每个大回合闭合时**裁决，兼顾对局节奏与竞技公平：
    1. **先手先达成归元时的智能快刀机制**（实现契约见 ADR 0007，频率实测见 ADR 0009）：
       - **常规秒结（后手未听牌）**：若后手当前盘面剩余未点亮侧数 **≠ 1**（即后手在半回合内即便抽中契合天干，数学上也绝无可能当场达成归元），系统**即刻当场判定先手获胜，对局立即终结**，绝不拖延无效垃圾时间；
       - **终轮天命揭牌（后手严格差 1 侧听牌）**：跳过后手的常规行动分支，由系统直接揭晓后手的一张天干进行判定。若该天干能点亮后手最后一侧达成归元，根据后发制人原则**判定后手获胜**；否则**判定先手获胜**。后手在揭牌轮中不执行任何常规动作，先手已锁定的归元成就不可撤销。
       - **实测频率**（10,000 局无头推演，`balancedStrategy` 自对弈，见 ADR 0009）：在先手先达成归元的对局中，常规秒结约 **38.6%**、终轮天命揭牌约 **61.4%**；揭牌占全部对局约 **33.3%**。本文档早期曾估计为 ~93% / ~7%，与实测不符，一律以 ADR 0009 为准。
    2. **后手先达成归元**：若后手在其自身行动中达成归元（先手此前未达成），因本大回合已然闭合，直接判定**后手获胜**。
- **次目标（回合上限结算）**：
  - **总回合定义**：正式对局上限为 **30 大回合（Round）**（每个大回合双方轮流各行动一次，**双方合计 60 次常规行动机会**）。爆发触发的连动额外回合为独立奖励行动，**不计入 30 大回合计数**。
  - **终局计分决胜**：若达到 30 大回合上限仍无人五行归元，扣除终局残留道损后比较双方累计总分，高者获胜；若分数相同，判定后手获胜。
  - **详细计分规则**（数值以 `src/core/logic/ScoreCalculator.ts` 的 `POINTS_CONFIG` 为准；行为分与状态分双轨制、2.5 倍攻击强化见 ADR 0002）：
    1. **动作基础分（`ACTION`）**：调息 CONVERT +50分，化 TRANS +30分，破 ATK +40分，强化 BURST +100分，强破 BURST_ATK +80分，自动吸纳 AUTO 0分，亢极散气 DISSIPATE 0分，消散过牌 PASS 0分。
    2. **状态转移分（`STATE_CHANGE`）**：
       - **己方建设提升**：疗伤修复 REPAIR_DMG（-1 → 0）+200分，点亮 LIGHT_UP（0 → 1）+100分，加持 BLESSING（1 → 2）+200分。
       - **敌方状态破坏**（按 ADR 0002 硬编码的 2.5 倍攻击强化）：致道损 CAUSE_DMG（0 → -1）阳 +300分 / 阴 +250分，破点亮 BREAK_LIGHT（1 → 0）阳 +200分 / 阴 +150分，削弱加持 WEAKEN（2 → 1）+200分。
    3. **稀有度加成（`RARITY_MULTIPLIER = 1.5`）——已定义但生产路径未接线**：非黑名单动作在一次结算分值之上追加 `分值 × (1 − 该动作发生概率) × 1.5` 的稀有度加成后取整；强化 BURST、强破 BURST_ATK、亢极散气 DISSIPATE、消散过牌 PASS 列于 `NO_RARITY_ACTIONS` 黑名单，不享受该加成。**注（工单 05 旋钮普查 / ADR 0011）：`applyRarityBonus` 在生产路径无调用点，该机制当前不生效；本节仅记录定义，接线或删除另立工单。**
    4. **节点归一里程碑（`GUI_YI_MILESTONE`）**：己方任意元素节点首次达成“归一”（阴阳双侧均达到 ≥1）时，一次性奖励 **+60 分**。
    5. **终局道损惩罚（`DAMAGE_PENALTY`）**：30 大回合终局结算时，盘面上每个残留的道损（-1）扣除 50 分。

### 2.2 基础动作机制（天道三态与能量守恒）
每回合开始时，当前行动玩家独立从十天干池（甲乙丙丁戊己庚辛壬癸）中随机抽取一个天干（代表特定五行属性及阴/阳极性），只作用于本方行动。
**核心能量模型**：每回合抽到的天干代表 **1 点外部输入能量**。玩家依据当前节点所处层级执行操作：

- **低位态：吸纳 (AUTO)**
  - **触发条件**：抽中天干对应节点侧处于虚空 (0) 或道损 (-1) 状态。
  - **执行效果**：自身干涸吸纳，该侧状态提升 1 级（-1 修复至 0，或 0 点亮至 1）。
  - **自身消耗**：无自身消耗（为纯收益 +1）。
  - **表现交互**：**纯自动无感流转**。界面不显示操作按钮，无额外倒计时，自动播放流星吸纳光效并结算棋盘状态。

- **中位态：道法流转（玩家自主选择）**
  - **触发条件**：抽中天干对应节点侧已处于点亮 (1) 或加持 (2)（且双侧未同时达到 2）。
  - **自身消耗铁律**：**自身那一侧绝对不扣除等级（保持原数值不变）**！由于自身已达稳态无法原地吸收，抽到的 1 点外部天干能量由玩家选择导向外部。严禁原地直接吸纳升 2。
  - **可选流转动作**：
    1. **调息 (CONVERT)**：
       - **门槛**：当且仅当**同节点对侧处于低位态（虚空 0 或道损 -1）时**才允许发动。若对侧已达到 1 或 2，**严格禁止调息**。
       - **效果**：将天干能量导向同节点对侧，使对侧提升 1 级（-1 修复至 0，或 0 点亮至 1）。自身侧数值不变。
       - **战略价值**：用于单侧已点亮时快速补齐对侧，抢先达成“归一”。
    2. **化 (TRANS)**：
       - **门槛**：必须抽中**阴天干**，且己方相生节点未达成 (2, 2) 亢极。
       - **效果**：将天干能量赋予己方相生节点。自身侧数值不变。
       - **目标规则（阴干优先）**：优先滋养相生节点的阴侧；阴侧满 2 之后才滋养阳侧。若相生节点双侧均为 2（(2, 2)），则不可选择化。
    3. **破 (ATK)**：
       - **门槛**：必须抽中**阳天干**，且对手相克节点未达成 (-1, -1) 全道损。
       - **效果**：将天干能量化为攻击轰向对手相克节点。自身侧数值不变。
       - **目标规则（阴干优先）**：优先压制对手阴侧；对手阴侧降至 -1 后才压制阳侧。若对手相克节点双侧均为 -1（(-1, -1)），则不可选择破。
    4. **消散过牌 (PASS)**：
       - **门槛**：若中位态当前盘面由于上述规则限制导致**没有任何合法动作可选**（例如：抽中阳干但克制目标全损无法破、对侧非低位态无法调息、且未归一或连动无法爆发），则触发消散过牌。
       - **效果**：天干自然消散过牌，直接结束本回合行动，流转给对手，绝不卡死对局，亦不得回退为原地吸纳。

- **极位态：亢极散气（强制回落）**
  - **触发条件**：当抽中天干所属节点的阴阳双侧均已达到 2（即达成亢极 (2, 2) 状态）。
  - **执行效果**：天道满溢则亏，玩家无法选择任何其他动作，强制按抽中天干的极性对应侧扣除 1 级（回落为 2,1 或 1,2），计 0 分。

### 2.3 进阶爆发机制与连动回合 (Burst Actions)
当抽取天干所属的己方元素节点已处于“归一”（阴阳双侧均 ≥ 1，如 (1, 1), (2, 1), (1, 2), (2, 2)）时，玩家除普通流转外，可发动高风险、高回报的过载爆发：

- **极性与消耗规则（必须对齐极性）**：
  - **强化 (BURST)**：必须抽中**阴天干**。主动消耗源节点的**阴侧 1 级**（自身阴侧 -1），将能量滋养己方相生节点（使其对应侧 +1），并**获得 1 次连动额外行动**。
  - **强破 (BURST_ATK)**：必须抽中**阳天干**。主动消耗源节点的**阳侧 1 级**（自身阳侧 -1），轰击对手相克节点（使其对应侧 -1），并**获得 1 次连动额外行动**。
- **目标判定**：强化与强破完全沿用“阴干优先”原则。若相生节点已为 (2, 2) 则无法发动强化；若对手相克节点已为 (-1, -1) 则无法发动强破。
- **决策权权衡 (Trade-off)**：
  - 普通【化/破】**不扣除自身等级**，安全稳健；
  - 【爆发】以**主动自损 1 级（可能拆毁自身归一状态或损失加持）**为代价，换取极其珍贵的连动先手节奏。
- **连动限制 (Chain Limit)**：
  - 发动爆发后立即在当前大回合内追加 1 次连动行动（当前行动方不变，重新抽 1 个天干）；
  - **单次大回合内严格禁止二次爆发**：在连动额外行动中，即使抽中归一节点，系统亦会强制锁闭【强化】与【强破】选项，防止无限制连击滚雪球。

### 2.4 唯一合法动作自动流转规范 (Single-Candidate Auto-Execution)
在某些特定盘面或规则边界下，规则引擎计算出的当前合法动作候选列表严格仅有 1 项（`|actions| === 1`）：
1. **低位态强制吸纳**：抽中天干对应侧处于虚空或道损，仅有 `AUTO`。
2. **极位态强制散气**：抽中天干对应节点已亢极 (2, 2)，仅有 `DISSIPATE`。
3. **连动额外行动收敛**：连动回合中抽中已归一节点，因禁调息且禁二次爆发，仅剩单一 `ATK`（阳干）或 `TRANS`（阴干）。
4. **单向极端封死**：生克目标某一侧达到极值（如克制目标双道损、或相生目标双加持），导致常规化/破被封，仅剩单一 `CONVERT`，或仅剩单一 `BURST`/`BURST_ATK`。
5. **全面锁死兜底**：所有生克、调息、爆发均不可行时，仅剩单一 `PASS`（消散过牌）。

**表现交互规范**：
- **无分支确定性自动流转**：当且仅当候选动作仅剩 1 项时，玩家面临的是“势在必行”的确定性局面，不存在实质分叉决策。表现层统一启动倒计时缓冲（约 0.75 秒）后**自动执行该唯一动作**，无需玩家进行冗余机械点击；
- **允许随时加速**：在倒计时期间，玩家点击屏幕任意区域或点击该单一按钮，可立即跳过倒计时直接触发结算；
- **不引入额外 PASS**：对于唯一动作为进阶爆发（BURST / BURST_ATK）的特殊情况，不额外追加主动 PASS 选项，严格保持游戏规则紧凑性与既定生克流转闭环。

## 3. 游戏模式 (Game Modes)
- **人机对战 (VS 天道 - 已实装)**：与内置 AI 博弈，AI 依据严谨的价值估值体系（自保 > 归一 > 攻击）做出最优决策。
- **Local PVP (双人对弈 - 规划中)**：本地同屏双人轮流操作对战，主打面对面策略竞技。
- **登塔模式 (PVE 挑战 - 规划中)**：长线单机爬塔关卡，作为获取局外外观代币的重要途径。

## 4. 局外系统与商业化 (规划中)
游戏**坚决不包含任何影响局内数值平衡的养成系统**，完全依靠外观与荣誉驱动。
- **灵石代币**：对局结算、完成成就与登塔通关产出，用于兑换外观。
- **个性化外观**：Q版卡通化身 Avatar、阵盘材质与施法流光动效。
- **成就勋章**：记录“极限翻盘”、“五行大满贯”等高光对局里程碑。

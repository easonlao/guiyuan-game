# 面向新玩家的前端美术与动画路线

Label: wayfinder:map

## Destination

确定一套帮助新玩家看懂对局的画面方向，并列清首批素材、动画及制作顺序，达到可以交给实现工作的程度。

## Notes

- 本路线只规划，不批量生成正式素材或全面重写前端。
- 用户没有游戏设计、前端设计开发经验；由 agent 提供具体选项和建议，用户判断喜好，不要求用户撰写美术提示词。
- 已确认：清楚为主、修炼氛围为辅。整体画面 → 行动反馈 → 角色动作。
- 先看参考图，再看当前游戏的粗略改版图；视觉方向见下方已决票，布局方向已由原型确认，细节及最终美术仍待验证。
- 会话使用 grilling 与 domain-modeling；参考资料收集使用 research；粗略改版使用 prototype。
- 既有实现与决定继续有效；新方案若冲突，明确提出再决定，不默默覆盖。
- **已有基础与继承边界**：盘面状态标记（归一金环／亢极外溢）、候选与按住预览（路径／幽灵态）、结算反馈与选项动画已实现并经用户部分验收（board-channel-and-marks 五票全部 resolved，归档于 `.scratch/archive/board-channel-and-marks/`，证据不是定义）。本路线在其基础上提升美术与表现范围，不从零重做前端。
- **前置验收 task**：角色图集「缓存优先最终版」尚待用户在微信开发者工具重新编译确认；小屏布局已有用户验收记录（同归档票 05）。这是[票 07](issues/07-wechat-atlas-and-layout-acceptance.md) 的范围，不混作美术决策。
- **角色生成这条线已挂起（2026-10-16）**：本地 ComfyUI／SDXL 出图效果未达到角色设计与动画所需；用户判断是「**先放下**」，不是「不行」（未定论）。票 04–08、相关调研与 `tools/sprite-pipeline/` 移到分支 `exp/character-generation`，票 04 里已拍板的决定见下。重来时先做票 04 的原题——**定最小样张与判断标准**——再选生成手段。
- 本地 tracker 约定见 docs/agents/issue-tracker.md。

## Decisions so far

- [收集清晰且有修炼氛围的画面参考](issues/01-reference-research.md)：已收集并核验不同视觉方向的官方截图，详见票内研究报告。
- [从参考画面确定喜欢与不喜欢的视觉特征](issues/02-visual-preferences.md)：以《弈仙牌》的场景和人物为参考，装饰克制；原型先试人物与棋盘并重、盘面清晰优先。

- [用当前游戏的粗略改版图确认画面方向](issues/03-layout-prototype.md)：用户选择 A（人物在上、棋盘居中）作为后续布局基线，尚未确认最终美术与细节。

### 角色设计（票 04 起，已挂起，原因见 Notes）

以下几条是用户在票 04 的试画过程中**拍板的决定**，不是过程记录，继续有效。

- **保留大头小身体的 Q 版比例**（约 3–3.5 头身），替换现有角色设计。
- **原创修士**，以传统文化作设计参考，不用传统名人（八仙／孙悟空／哪吒方向已否决）。
- **画风基线**：减弱粗黑描边、增加头发与衣服层次、保留风格化 Q 版（用户回复「这个可以」）。
- **否决清单**：葫芦游侠、符纸剑修、松枝小剑仙、行云剑客、黑白金分层长袍，以及「儿童卡通画法」。
- **顺序**：先人物静态样张 → 放回 A 布局检查 → 再配山水背景；棋盘、文字与操作提示继续由代码绘制；施法与受击动画后置。

- 因视觉调整而重做核心游戏规则。

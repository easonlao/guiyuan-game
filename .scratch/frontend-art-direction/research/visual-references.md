# 画面参考：先比较清晰度，再比较修炼氛围

## 结论与边界

提供三个差异明确的比较对象，不在本票选定画风：**《弈仙牌》的场景与角色、《Slay the Spire》的操作分区、《Inkulinati 神笔谈兵》的浅底与线条**。这是研究建议，不是对当前游戏的改版定案。

需求依据：[路线 map](../map.md)、[研究票 01](../issues/01-reference-research.md)。用户已选择「清楚为主、修炼氛围为辅」，先看参考图，再看当前游戏粗略改版。本票只研究；未读取游戏代码，未生成素材，未实现改版。

## 来源与视觉核验

- 使用 Exa 搜索官方 Steam 商品页。最终只引用商品页和该商品的 Steam 商店截图，不采用 Steam 社区用户截图或第三方截图站作为证据。
- 从 Steam 的商品数据接口取得截图地址，下载原图后实际打开查看。下面引用的 A1、A2、A3、B1、C1 **均已视觉核验**，并非只根据搜索摘要推测画面。
- 核验的是商店提供的静态截图，**不是运行游戏验收**。截图不能证明按钮可点击范围、悬停提示、动画节奏、当前版本一致性或手机上的可读性。文中「更突出」「可借鉴」属于研究者的视觉判断，不是用户测试结果。
- 图片仅以外链展示；没有将商业图片加入仓库或游戏资源。若外链失效，请回到对应官方商品页的截图栏。商店截图可能更新。

## A｜《弈仙牌》：具象修炼场景与完整人物

[官方 Steam 商品页][A] · [对战原图 A1][A1] · [准备界面 A2][A2] · [选择界面 A3][A3]

![弈仙牌官方对战截图：人物分列两侧，建筑与山水铺满背景][A1]

### 已看到什么

| 关注点 | 对应截图中的观察 |
|---|---|
| 布局 | 对战图把头像放在上方两角，完整人物分列左右，卡牌沿底边排列；左侧还展开一张大卡牌。[A1] 准备图则以中部横排卡牌为主体，角色移到左下。[A2] 两者是不同界面，不能混成同一布局。 |
| 背景 | 对战图有青蓝色山体、水面、层叠屋顶及前景草地，并不是纯留白背景。[A1] 准备图的背景较暗，卡牌与金色装饰更显眼。[A2] |
| 按钮 | 准备图右上有带兽面装饰的「准备」控件。[A2] 选择图用大面积浅底承载选项，底部用黑底白字的「确定」按钮；第一项采用深色底，与其他浅色项形成区别。[A3] 只观察外观，不推断交互状态切换规则。 |
| 角色 | 同一对战图同时出现圆形头像与完整人物，人物有细致服饰、武器及光效。[A1] |

### 可以借什么／不要照搬什么

- **研究建议：**借鉴建筑、衣饰与少量纹样提供修炼氛围；比较「人物在画面中有完整身体」是否比只看头像更合喜好。选择界面也提供了「有笔墨感，但确认按钮仍用明确文字」的例子。[A1][A3]
- **不直接套用：**画面里的密集卡牌、装饰边框与背景细节同时存在。[A1][A2] 如果整体照搬，可能与本项目「清楚为主」的目标冲突；这只是风险判断。不能因为主题相近就迁入它的卡牌流程或覆盖现有规则。
- **请用户比较：**你喜欢的是人物与远景，还是连边框、金色装饰也想要？可以只喜欢其中一部分。

## B｜《Slay the Spire》：深色舞台与独立操作区

[官方 Steam 商品页][B] · [战斗原图 B1][B1]

![Slay the Spire 官方战斗截图：角色在中部两侧，手牌在底部，End Turn 在右下][B1]

### 已看到什么

| 关注点 | 对应截图中的观察 |
|---|---|
| 布局 | 顶边是一条资源信息带；角色分列中部左右；手牌集中于下边；右下有独立的「End Turn」按钮。图中正展示一张放大的卡牌与闪电效果。[B1] |
| 背景 | 建筑和地面以暗红、深褐为主，亮青色卡牌边缘、白色闪电与浅色文字形成明显明暗差异。[B1] |
| 按钮 | 「End Turn」使用有边框的独立面板和文字，不与手牌画在同一个容器内；左下资源也有单独外框。[B1] |
| 角色 | 人物以完整身体和较简洁的轮廓呈现；血条放在人物下方，状态小图标紧邻血条。[B1] |

### 可以借什么／不要照搬什么

- **研究建议：**借它的分区方法：状态、对战主体、可执行操作各有位置；角色附近放该角色的关键信息。可以借信息层级而不借暗黑题材或卡牌玩法。[B1]
- **不直接套用：**图中的整体暗色与地牢场景不是修炼氛围；底部手牌也不是现有游戏必须新增的东西。[B1] 不能仅凭截图声称新玩家一定更易懂；图标含义和字体大小仍需在本游戏原型里验证。
- **请用户比较：**是否喜欢这种「角色与操作分开、重要操作有明确文字」的感觉？即使不喜欢深色背景，也可以保留这个答案。

## C｜《Inkulinati 神笔谈兵》：浅色纸面与线描角色

[官方 Steam 商品页][C] · [完整对局原图 C1][C1]

![Inkulinati 官方完整对局截图：浅色书页，深线角色，操作图标集中于底部][C1]

### 已看到什么

| 关注点 | 对应截图中的观察 |
|---|---|
| 布局 | 中央展开书页承载战场；两侧底角各有大头像与数值标签；底部中央集中两排圆形图标；顶部也排列双方圆形头像。[C1] |
| 背景 | 大面积米黄色纸面上有较淡的城堡线稿，前景角色、平台和梯子的轮廓更深。页面并非完全无纹理或无装饰。[C1] |
| 按钮 | 底部控件以圆形边框和手势等图标为主，截图里没有为每个图标常驻显示动作名称。[C1] 因此不能把「图形整齐」直接等同于「新玩家知道怎么点」。 |
| 角色 | 动物与人物都使用黑色轮廓、局部平涂；服饰、盾牌与头像边框出现橙色、蓝色呼应。[C1] 观察只涉及视觉对应，不推断完整阵营编码规则。 |

### 可以借什么／不要照搬什么

- **研究建议：**借「浅底、少量场景细节、深色主体轮廓」的分离方式。若用户喜欢，可在后续粗略改版中探索原创淡纸色与山水线稿；这是迁移设想，**不是说原作采用中国水墨或修仙题材**。[C1]
- **不直接套用：**中世纪手稿题材由官方商品页明确说明。[C] 其中动物造型、字体、书页战场和多层平台不能直接变成本游戏风格或规则。底部纯图标方案也不宜未经新玩家验证就照搬。[C1]
- **请用户比较：**你喜欢这种亮、空、线条清楚的底子吗？还是觉得太像书本，不够像角色对战？

## 下一步：请比较组成部分，不必选整套游戏

下面是给用户的问题，不是已作出的决定：

1. **背景：**A 的具体山水建筑、B 的深色舞台、C 的浅色纸面，哪个看起来最舒服？哪个最容易抢走你对对局的注意力？
2. **角色：**更喜欢 A 的细致完整人物、B 的简洁完整人物，还是 C 的线描人物？允许回答「想要 A 的感觉，但少一点装饰」。
3. **按钮与分区：**更喜欢 A3 的浅底选项与黑底确认，还是 B 的独立操作区？C 的圆形图标是否让你不知道该点什么？
4. **第一眼：**每张图你先注意到什么？你希望本游戏第一眼突出角色、盘面，还是当前可做的操作？

用户比较后，下一步才把喜欢的组成部分放进**当前游戏的粗略改版图**，保留既有规则与已确认决定；不把这三张图当作必须三选一的方案。本票没有验证当前游戏适配，也没有作出最终风格选择。

## 资产使用边界

**可查看、可参考，不等于获准复用资产。**本研究没有取得角色、背景、图标、字体或界面美术的复用授权。不要把图中内容裁切进正式游戏，也不要把商店公开展示理解为商用许可。若后续确需使用某项资产，应另行核验该资产的许可或向权利人取得授权；本票不作授权结论。

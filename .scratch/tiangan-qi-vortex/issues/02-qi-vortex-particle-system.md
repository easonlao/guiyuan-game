# 02: 五行灵气光旋粒子系统与正反向流场实现

**What to build:** 
在天干符文动效层实现基于 Canvas 2D 的轻量灵气粒子系统，在天干显现前，从当前行动方的 5 个五行主印释放灵气光尘群，按阵营差异的旋涡轨迹（己方顺时针、对方逆时针）向心汇聚到天元中心，形成视觉可辨的五行聚气效果。

**Blocked by:** 01: 移除符文浮动文字与入场时长参数重构

**Status:** resolved

## Acceptance Criteria

- [x] 在 `RuneFlightView` 中增加灵气光旋粒子发射与状态更新逻辑，粒子池大小适度（如每主印 12~18 颗），确保 60FPS 流畅运行且无 GC 压力。
- [x] 粒子发射源精确对齐当前行动方的 5 个主印坐标（读取 `this.board.elements` 对应 `player === owner` 的位置），各主印粒子颜色取对应五行的明亮色（`WUXING_PALETTE[elem].light`）。
- [x] 起点五行主印在发射初期伴随柔和的光晕脉冲波纹（0.0s ~ 0.4s）。
- [x] 实施正反向向心旋涡流场：己方（P1 内环）微粒顺时针旋转汇聚，对方（P2 外环）微粒逆时针旋转汇聚。
- [x] 增加测试用例覆盖粒子系统在不同行动方（P1 / P2）触发下的初始化与每帧 update 正常推进。
- [x] 运行 `npm run check:quick` 通过。

# 按住预览：路径箭头与幽灵结果态

Status: ready-for-agent

## 用户目标

按下按钮之前，就想看到这一下会走哪条路、打到哪里、变成什么样。

## 范围

- 按住 / 点选某个按钮时：该按钮的候选弧加快；叠加路径箭头——化与强化沿内环顺时针的弧箭，破与强破沿径向的箭；目标侧显示「下一步」幽灵态（半透明的目标等级形态）。
- **强化与强破的目标侧不在载荷里**（解析时逐次重读盘面、各自按阴侧优先决定）。它们的预览必须真跑一遍解析器拿到两级的真实落点，不得沿用 `game-scene.ts` 现有兜底的近似落点。
- 只预览真实会发生的净变化：PASS、目标未变（如强破打已 `(-1,-1)`）不画幽灵态。
- 复用既有管道（`resolveActionPath` / `setActivePaths` / `BoardConnectionView.isActive`），本票只补渲染与交互。

## 与票 02 的衔接

- 候选弧加速、路径箭头与幽灵态共用一个时钟：票 02 建立的表现层时钟 `BoardView.tick(dt)`，不再另起。
- 按住时的运动要在票 02 的节点级常驻流动（归一金环流光 / 亢极元素外溢）之上仍读得出「我正在预览这一下」。

## 验收

- 破 / 化 / 强化 / 强破 各一次按住预览截图，幽灵态与结算后的真实盘面逐侧一致。
- PASS 与净零变化不伪造预览。
- 行为测试覆盖「按住 → 弧加速 + 路径 + 幽灵态」与「松开 / 取消 → 回到决策期」；`verify` 通过。

# 04: 五行配方系统

**Type:** task
**Blocked by:** 02, 03
**Status:** open
**Slice:** S4

**What to build：**

1. `params/materials.ts`：金木水火土五套完整配方——配色 ramp（四色）+ 形状参数（smear 宽度、spark 数量/形态、burst 形态、弹道形态）+ 节奏参数。五行是整套表现差异，不是换色：火=爆闪+升火星、水=涟漪+坠露、金=星闪+直线光痕、木=花瓣+飘叶、土=地裂+落石尘环（原型里五种形态均已实现并经用户走查）。
2. 特效触发时按目标节点的五行属性自动选配方，触发瞬间锁死配方（播放中途不受后续选择影响）。
3. 校验函数扩展：五套配方必须齐全、字段完整。

**验收：**
- 同一攻击动作打在五种五行节点上，呈现五种可辨认的形态；用户蒙眼测试：不看标签能说出是哪种五行。
- `npm run verify` 全绿；产物重建。
- 收尾：事件 schema 与配方契约回写 `docs/LLD.md`，框架机制回写 `docs/HLD.md`，删除 `.scratch/vfx-framework/`。

**为什么最后做：** 材质是横切关注点，需要 02/03 的原语全部就位后才有东西可配。

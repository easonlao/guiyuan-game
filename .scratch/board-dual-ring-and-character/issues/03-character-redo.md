# 03: 角色重做

**What to build:** 角色从约 46px 的角落头像变成约 100–120px 的全身像素画，姿势变化（待机/攻击/结印/受击）清晰可辨；并新增「归一庆祝」与「终局胜/负」两类角色反馈，让里程碑与胜负有仪式感。

**Blocked by:** 01 (法盘同心双环)

**Status:** ready-for-agent

放大必须提高逻辑分辨率重画，不能 `ctx.scale` 放大现有块状像素画。布局回顶部左右角（放弃放盘侧——空间算不出来）。「归一庆祝」用现成的 `node:stateChanged` 事件驱动，不在场景里手写盘面比对。

- [ ] 现有全身像素角色提高逻辑分辨率重画，屏幕上约 100–120px，姿势/呼吸/气泡/横幅保留且随尺寸清晰可辨。
- [ ] 角色布局在顶部左右角（己方左、对方右），与顶部比分/回合条协调，不遮挡法盘。
- [ ] `CharacterActionState` 联合类型扩展，新增「归一庆祝」与「终局胜」「终局负」状态；绘制与配色映射同步更新，新状态不静默落回默认分支。
- [ ] 「归一庆祝」由 `node:stateChanged` 事件触发（某侧由 <1 变 ≥1 且对侧已 ≥1 时），按归属方在对应角色上播放。
- [ ] 终局时胜方角色播「胜」、负方播「负」。
- [ ] 测试断言：新状态的姿势与配色映射正确；`node:stateChanged` 触发归一庆祝且归属方正确。

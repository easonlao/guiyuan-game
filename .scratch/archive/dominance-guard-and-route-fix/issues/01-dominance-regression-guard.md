# 01: 占优回归护栏 (Dominance Regression Guard)

**What to build:** 让「激进压制对全部其它策略严格占优」这一事实变成被测试钉住的约束，而不是只写在文档里的观察。

现状：审计测出该占优的座次平衡胜率为 57.80%–80.85%，但这组数字只存在于 5 个 markdown 文件里，没有任何测试会因为它变化而失败。全套 626 个测试中，唯一涉及真实对拼矩阵的占优断言是「报告文本里含有『占优』或『矩阵』字样」——出现占优时它反而更容易通过。因此下一次计分改动如果把某条策略改成新的占优，测试会全绿，改动人得不到任何提示。

本票要补上这个保障。**注意方向：现状下占优确实存在，所以本票写的是特征化断言（把现状钉住），不是「断言不存在占优」。** 后者今天就会红。正确的作用是绊线——改动计分后这条断言会失败，逼改动人显式确认「旧占优是否消失、有没有换来新占优」。

成本已确认很低：200 局/格的全矩阵约 2.5 秒。

**Blocked by:** None (can start immediately)

**Status:** closed

- [x] 特征化断言：现状计分配置下，激进压制对全部六个对手严格占优（6/6）
- [x] 关键格钉成带容差的基线（至少含激进压制对其余六者的座次平衡胜率）
- [x] 断言在计分被扰动后必须失败——用一次刻意的计分改动验证它确实会红
- [x] 断言失败的输出足以定位：哪一格、期望值、实际值、差多少
- [x] 运行时间可接受（优先小样本，必要时缩到测试可接受的量级，并注明样本量与噪声水平）
- [x] 在文件里写明这条钉**预期会被 03 打破**，以及打破时该做什么

# Spec: 让压制的相对回报随盘面翻转，使每个行为都有价值 (dominance-guard-and-route-fix)

## Problem Statement

AI 对局里「**永远压制**」是最好的打法。

审计测出：激进压制对全部六个其它策略严格占优，座次平衡胜率 57.80%–80.85%。压制型自对弈同时表现为九成以上的流局率与六成以上的先手胜率——**个体最优、集体无聊**。

根因已测清：占优由**计分**造成，不是盘面造成。完全剥离计分后，激进压制只赢 2/6，没有任何策略严格占优。

**但「让压制不再最优」不是正确的目标。** 剥离计分那个实验本身就是反例：那时**推进**处处最优，平衡与剥离计分各 5/6 近占优。从"单一压制解"换成了"单一竞速解"，玩家仍然没有选择。

**项目负责人确认的设计意图：游戏要因为场上局势而使得博弈有可能，每一个行为都有价值。**

这句话给出两条要求：

1. 压制必须在**某些**盘面状态下严格优于推进，在**另一些**状态下劣于推进。只有相对价值随局势翻转，"根据局势切换"才有空间。
2. **没有任何动作应该被支配**——每一个行为都要在某种局势下成为最优选择。

而现在的代码里，**没有任何机制让压制的价值随局势递减或产生代价**：

- 唯一的封顶是每侧等级 `[-1, 2]` 的钳制。
- 【破】的盘面收益是平的 `+1`，只在打**加持侧**（等级 2）时为 `0`，对手全道损时硬封顶。
- 计分确实随目标等级变化，但在总量上让压制**处处**更优。

所以压制的相对价值只有两种状态：**处处更优**（现状）或**处处更差**（剥离计分）。两种都没有选择。

**后果**：后续所有平衡工作都卡在这里。ADR 0011 已把路线定为「修计分与终局结算口径」，但那条路线只写了"让压制不再最优"，需要按本 spec 的目标说完整。

## Solution

让**压制的相对回报随盘面状态翻转**，使每一个行为都在某种局势下有价值。

具体做法是三步：

1. **先造度量工具。** 现在没有任何工具能回答"这个动作在什么局势下是最优的"。要按项目既有政策（工具是永久基础设施，先完善工具再做测试）先把这个度量造出来：**动作价值普查**——对每一个动作类型，找出它在何种盘面状态下是最优选择；若某动作在所有被测状态下都被支配，报出来。
2. **再有界搜索候选规则。** 在计分与终局结算口径里找一个候选改动，让它同时满足四条验收标准（见下）。**最多试 5 个候选**。
3. **然后落地。** 采纳通过的候选，复跑并重设护栏带，更新绊线，同步文档与 ADR。

**四条验收标准，缺一不可：**

1. **无严格占优**——改动后不存在对全部对手严格占优的策略。
2. **每个行为都有价值**——没有动作在所有被测盘面状态下都被支配。
3. **护栏全绿**——归元率与先手胜率带全部在带内，且没有把任一模式推到极端值。ADR 0010 的两个候选计分改动都击穿了护栏（关闭模式的平衡归元率被推到 99.90% / 99.88%），只看前两条会选出把游戏打坏的解。
4. **动态策略打赢全部静态预设**——这是设计意图的直接检验。现有六个预设全部是固定权重，而设计意图是动态的。此前测出的"切换没用"是在**压制处处最优**的规则下取得的：在那个规则下任何切换策略的上限就是永远压制，所以那不是对设计意图的检验。

**搜索有界。** 5 个候选都不满足四条标准，就停下，记录该结果并升级为「需要改规则而非改计分」的决定。**这是一个有效结论，不是失败。**

## User Stories

1. 作为玩家，我想要每一个动作在某种局势下都是正确选择，这样我的决策才有意义，而不是永远按同一个键。
2. 作为玩家，我想要根据场上局势在推进与压制之间切换，这样我玩的是博弈，不是固定套路。
3. 作为玩家，我想要对手快归元时压制变得有价值，这样"不阻碍对手就会输"成立。
4. 作为玩家，我想要只能打到加持侧时压制变得没价值，这样"看准目标"有回报。
5. 作为玩家，我想要己方快归元时推进成为正确选择，这样"我更快归一"成立。
6. 作为玩家，我想要压制不是无代价的，这样持续压制不会成为唯一解。
7. 作为玩家，我想要对局不会因为双方都压制而九成以上拖到回合上限，这样流局是例外而不是常态。
8. 作为玩家，我想要先手不因为压制型打法而获得十几点的额外胜率，这样座次不影响公平。
9. 作为平衡调整者，我想要一个能回答"这个动作在什么局势下最优"的工具，这样我不用靠猜来判断一个动作有没有价值。
10. 作为平衡调整者，我想要工具报出被支配的动作，这样"每个行为都有价值"这条目标可以被验证，而不是只能被声称。
11. 作为平衡调整者，我想要四条验收标准一次跑完，这样我不会只优化其中一条而把游戏打坏。
12. 作为平衡调整者，我想要护栏在每次候选验证时都复跑，这样我不会重复 ADR 0010 那种把归元率推到 99.9% 的改动。
13. 作为平衡调整者，我想要搜索有次数上限，这样我不会无限试下去。
14. 作为平衡调整者，我想要搜索失败被当成有效结论记录下来，这样"改计分走不通"这件事能成为下一步的依据。
15. 作为平衡调整者，我想要改动前后逐格对照，这样我能看见哪些强弱关系被翻转。
16. 作为平衡调整者，我想要流局率与先后手胜率成对报告，这样我不会把"个体最优、集体无聊"误读成两个独立现象。
17. 作为平衡调整者，我想要候选规则不依赖任何死参数，这样我不会在"改了没反应"的旋钮上白跑一格。
18. 作为 AI 编码代理，我想要动作价值普查有明确的接口和断言，这样我改计分后能立刻知道是否造出了被支配的动作。
19. 作为 AI 编码代理，我想要候选验证是一条命令跑完，这样我不必手工拼装对照表。
20. 作为 AI 编码代理，我想要绊线在计分被改动时变红，这样我会被强制确认"旧占优是否消失、有没有换来新占优"。
21. 作为 AI 编码代理，我想要落地步骤包含护栏重设，这样新规则下的红线不会沿用旧规则的数字。
22. 作为未来读文档的人，我想要 ADR 记录目标从"让压制不再最优"改为"让相对回报随盘面翻转"的理由，这样我能理解为什么剥离计分那条路被否决。
23. 作为未来读文档的人，我想要被否决的候选与它们各自失败在哪一条标准，这样后来者不必重试。
24. 作为项目负责人，我想要这次改动有可复跑的测量支撑，这样"游戏能否成立"这个问题最终有一个能验证的答案。
25. 作为项目负责人，我想要测量台与实验命令不因本工作被回退，这样每一轮都在积累而不是重建。

## Implementation Decisions

**接缝：两个，均为既有接缝，不新增。**

1. **主接缝：无头推演入口。** 实验运行器已经能跑「策略 × 计分配置 × 规则模式」的对照矩阵，命令齐全。候选验证、护栏复跑、动态策略复跑都从这里发起。
2. **场景接缝：纯动作解析器。** 它是纯函数，输入是完整游戏状态与一个动作，输出结算结果。**动作价值普查必须建在它上面**——因为要问的是"这个动作在**这个**盘面上值多少"，而不是从随机对局里统计。

**候选改动若是现有旋钮的取值**，零新接缝。**若是新结算机制**，需要在规则模式联合类型上加一个值、或在推演选项上加一个字段。那是代码扩展，**不是新的测试接缝**。

**要新增的模块**

3. **动作价值普查。** 对每个动作类型，在受控盘面上比较它与同盘面其它可用动作的价值，找出它成为最优的盘面条件；报出在所有被测状态下都被支配的动作。它消费既有接缝与既有的盘面构造器、盘面进度指标。
4. **候选验证命令。** 一条命令跑完四条验收标准并输出对照报告。

**度量口径**

5. 「被支配」的判定用**动作价值**，不是胜率：在给定盘面上，某动作的价值严格低于另一个可用动作，即为该盘面下被支配。若一个动作在所有被测盘面状态下都被支配，报为被支配动作。
6. 被测盘面状态必须覆盖既有的阶段划分（低位态期 / 中盘 / 残局），并覆盖既有实测出的两个阶跃条件（目标侧为加持、对手全道损）。
7. 压制度量沿用既有口径（等级下降量），不得退回「未点亮侧数」的旧口径——旧口径会把「加持 2 → 点亮 1」记为 0 削弱。

**验收标准与执行**

8. 四条标准必须一次跑完并同时报告，禁止只报其中一条。
9. 护栏带：归元率 `[0.75, 0.95]`、先手胜率 `[0.45, 0.55]`、堆内存增量 `< 15MB`（500 局、平衡自对弈、固定种子）。ADR 0001 的 `25%–80%` **没有 live 断言，不得用作红线**。
10. 搜索预算：**最多 5 个候选**。每个候选都必须跑完四条标准。用完即停并升级。
11. 候选不得依赖任何死参数。死参数清单以旋钮普查为准。
12. 动态策略复用既有的动态切换策略作为基准；若它在新规则下仍不能全胜，必须区分「设计意图不成立」与「该实现不足」。

**落地**

13. 采纳通过的候选后，必须复跑并**重设**护栏带——现有带描述的是改动前的现状，不是新游戏的目标值。
14. 必须更新绊线：它现在钉住「激进压制 6/6 占优」，改动后应读作「不存在严格占优」。
15. 必须记录被否决的候选及各自失败在哪一条标准。
16. 测量台与实验命令不得因本工作被回退。

## Testing Decisions

**什么算好测试：** 只测外部行为，不测实现细节。断言写在两个接缝上——无头推演入口与纯动作解析器的输出，不触碰内部数据结构。

**要测的模块与断言：**

- **动作价值普查**：给定一个构造出来的盘面，它能正确报出各可用动作的价值排序；能报出被支配动作；对已知的被支配情形有断言。
- **口径锁**：压制度量按等级下降量计（`2→1`、`1→0`、`0→-1` 各记 1），旧口径的相反结论有回归测试锁住。
- **候选验证命令**：四条标准各自可独立触发失败；报告同时包含四条；无严格占优的结论必须附带对拼矩阵。
- **护栏**：带内断言、堆内存增量断言。
- **绊线**：特征化断言在计分被扰动时必须失败——已由既有绊线证明会红，改动后按新状态更新。
- **确定性**：同一随机种子与同一决策序列产出同一结果。

**现有先例：**

- 动作价值普查参考既有盘面构造器与盘面进度指标的测试方式。
- 候选验证参考既有实验运行器测试：矩阵格数、座次互补、自对弈基线 ±1.5pp、确定性。
- 护栏参考既有护栏测试（500 局自对弈、三条带）。
- 口径锁参考既有指标口径陷阱回归测试（含"先证明能抓到旧错误"的做法）。

## Out of Scope

- **改 AI。** ADR 0011 已否决把动态切换做成生产策略（实测对最强预设只赢 +0.71pp）。本 spec 只改计分与终局结算口径。
- **把 board-only 当生产规则。** 它把近占优转移到平衡 / 剥离计分（各 5/6），不是解。
- **具体候选数值。** 那是候选搜索票的产出，不是 spec 的预设。
- **生产环境是否采用某条动态规则。** 动态策略在本 spec 里是**检验工具**，不是交付物。
- **表现层**（玩家能看到什么）。
- **通用规则变体框架**等"回答任何问题"的抽象。

## Further Notes

- **目标句的改写及理由。** ADR 0011 决策 1 的目标写作「让计分不再把持续压制回报为最优解」。这个目标不完整：它的终点是 board-only 的结局——从单一压制解换成单一竞速解。本 spec 按项目负责人确认的设计意图改写为「让压制的相对回报随盘面翻转，使每一个行为都有价值」。这是把目标说完整，不是改决策。
- **为什么先造工具。** 项目既有政策：工具是永久基础设施，只有实验脚手架可以丢弃；先完善工具再做测试。动作价值普查是"每个行为都有价值"这条目标的唯一度量，没有它这条标准无法验证。
- **为什么「被支配」用动作价值而不是胜率。** 胜率是策略层的度量，回答不了"这个动作本身有没有价值"。用胜率检验会重复审计已经暴露的那个错误——自对弈归元率无法回答占优问题。
- **代价。** 若以后规则大改（节点、动作、胜负条件变了），动作价值普查与候选验证命令可能要返工。
- **若搜索失败。** 5 个候选都不满足四条标准，则本 spec 的结论是"改计分走不通，需要改规则"。届时应另立决定票并补 ADR，而不是继续在本 spec 里加候选。

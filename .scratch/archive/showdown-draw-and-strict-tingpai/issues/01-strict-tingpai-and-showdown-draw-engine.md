# 01: 核心状态机听牌收紧与天命揭牌决胜闭环

**What to build:**
按照 ADR 0007 规范收紧听牌临界态并重塑先手归元后的终轮决胜状态机：
1. 听牌临界态收紧：将 `isBoardTingPai` 判定收紧为仅当盘面未点亮侧数（等级 < 1 的侧数）严格等于 1 时判定为听牌；若未点亮侧数 ≥ 2，判定为未听牌。
2. 终轮天命揭牌决胜流转：当先手（P1）达成五行归元且后手处于听牌临界态时，状态机彻底阻断后手进入常规行动半回合（不派发常规候选动作，禁止后手执行常规动作或爆发连动），直接由系统确定性抽取一张天干进行决胜裁决：
   - 检测揭晓的天干是否能通过合法操作（自动吸纳、化气、调息）点亮后手最后未点亮的那一侧；
   - 若能补全点亮：判定后手反败为胜（`winner: 'P2'`，达成五行归元，后发制人）；
   - 若无法补全点亮：判定先手获胜（`winner: 'P1'`）；
   - 对局立即终结（`isGameOver: true`，`endReason: 'GUI_YUAN'`）。
3. 若后手未听牌（未点亮侧数 ≥ 2），先手达成五行归元时即刻当场秒结（`winner: 'P1'`）。
4. 事件广播与核心单测对齐：在事件总线中广播天命揭牌关键信息，补充全面的差一侧天干命中与未命中测试，保持全套单元测试通过。

**Blocked by:** None (can start immediately)

**Status:** resolved

- [x] 若抽中天干使 P2 达成归元，判定 P2 获胜；若未抽中能达成归元的天干，判定 P1 获胜。

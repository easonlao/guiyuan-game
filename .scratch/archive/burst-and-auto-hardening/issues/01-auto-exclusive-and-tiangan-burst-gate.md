# 01: 天干虚空强制自动吸纳与当前天干归一爆发判定守卫

**What to build:**
重构合法动作生成器（ActionCandidates），确立两大核心规则：
1. **吸纳唯一排他性**：当抽到的天干对应侧处于虚空 (0) 或道损 (-1) 时，吸纳（AUTO）为唯一可选动作（自动行为，无任何其他分支候选），彻底屏蔽调息（CONVERT）、相生化（TRANS）、相克破（ATK）及任何爆发动作。
2. **规则 A（爆发绑定当前天干归一）**：只有当**当前抽取的天干所属节点已达成“归一”**（阴阳两侧均 >= 1）时，才允许基于该天干节点生成强化（BURST）与强破（BURST_ATK）。若当前天干节点未归一（哪怕棋盘上其他五行节点已归一），绝对禁止生成爆发动作。
3. **五行全覆盖与无头回归**：测试用例全面覆盖木、火、土、金、水所有五行在虚空/单侧点亮/归一状态下的候选动作生成，确保既有 112 个单元测试与无头基准推演全部通过。

**Blocked by:** None (can start immediately)

**Status:** resolved

- [x] 当天干对应侧为虚空 (0) 或道损 (-1) 时，`getAvailableActions` 返回且仅返回一个 `AUTO` 动作，排斥所有其他选项。
- [x] 仅当当前抽取天干对应五行节点满足 `isNodeGuiYi(node)` 时，才允许生成该节点的 `BURST` 与 `BURST_ATK`。
- [x] 若当前天干节点未归一（如仅单侧点亮，或为虚空），即使其他五行节点归一，也绝不生成任何爆发动作。
- [x] 单元测试覆盖全部五行（木、火、土、金、水）在虚空、单侧点亮、归一场景下的合法动作断言。
- [x] 既有全部单测与无头推演策略测试保持通过。

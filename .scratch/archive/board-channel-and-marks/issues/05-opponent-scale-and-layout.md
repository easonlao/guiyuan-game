# 外环放大与环间距重算

Status: resolved

## 用户目标

对手盘太小太暗，而它的归元进度决定我该追还是该防。暗化已经撤销（票 01），现在把尺寸补上。

## 范围

- 外环主印放大到接近内环（约 0.92）；归属区分完全交给环带的实线 / 虚线与「你 / 天道」标签。
- `BoardView.resize` 的可用高度公式把节点级标记的外沿算进去——现在只保证主印本身不重叠，加了归一金环 / 亢极元素外溢后这个保证就失效；外沿口径用票 02 定下的 `NODE_AURA_OUTSET_RATIO`（归一 / 亢极柔光与底晕共用同一个常量）。
- 像素取值以代码常量为真源。

## 验收

- 320×568（含窄屏 safeTop 模拟）/ 390×844 / 460×900 截图：外环主印可读，环与相邻主印不相交，不与操作栏或结果条重叠。
- 行为测试覆盖 resize 后的半径 / 缩放 / 不重叠；`verify` 通过。

## 实施结果

- `OPPONENT_SEAL_SCALE` 0.82 → **0.92**（`src/minigame/views/board-view.ts`）。归属仍由环带实线 / 虚线与
  「你 / 天道」标签承担，尺寸差不再是归属信号。
- `BoardView.resize` 的避让口径重写，分两套：
  - **环间距**按新增的 `NODE_RING_OUTSET_RATIO`（金环外沿 = 环半径 + 半线宽）预留，同环靠比例与
    可读性下限兼管、跨环直接推外环半径；
  - **盘面上下外沿**按票 02 的 `NODE_AURA_OUTSET_RATIO` 预留（底部含归元图例），避免外溢或图例越出
    内容边界。**没有**拿 `NODE_AURA_OUTSET_RATIO` 去约束环间距——那圈柔光渐隐到 0，交叠只读成更亮的一层晕，
    拿它避让会把主印压得看不清（ADR 0018 勘误已记这条取舍）。
- 图例的几何（基线 / 字号）提为常量，`_drawGuiYuanLegend` 与 `resize` 的高度预算共用一份。

## 需求方定夺落地：最窄屏主印变小的缓解（微调 GameScene 边距）

针对 320×568 + 微信胶囊（safeTop 88）时内容区仅 246px、主印缩小到 12.5px 的问题，
在复审中经需求方选定 **方案 A（放宽 GameScene.layoutBoard 边距预算）**：
- `GameScene.layoutBoard` 在 `compact && safeTop > 24` 时，顶部偏移由 100px 收紧为 88px（仍留出 8px 头像底安全距离），底部预留由 64px 收紧为 46px（与上一招结果条仍有 18px 安全间距）；
- 净增加约 30px 可用垂直高度，主印半径由 12.5px 回升至 14.1px+（面积增加约 27%），无元素重叠。

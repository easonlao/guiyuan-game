# 05: 命令行批量对阵与基线比较报告

**What to build:** 一条命令运行小规模基线与实验配置对照，生成可追溯的机器可读结果和简明人类报告。

**Blocked by:** 03 — 可复现随机对局与三类公开信息策略；04 — 显式选择实验计分配置。

**Status:** resolved

- [x] 提供项目命令入口，支持小规模默认运行、样本数、种子、输出位置及规则配置选择。
- [x] 使用配对随机样本，覆盖策略角色互换与先后手互换；每场双方使用同一规则版本，记录实际初始状态与随机输入。
- [x] 说明额外行动会改变天干接收玩家，配对天干流不意味着双方拥有完全相同的个人机会。
- [x] 报告胜平负矩阵及胜负价值（胜 1、平 0.5、负 0）、不确定性、动作频率、对局长度、归一获胜与上限结算比例、推进与破坏轨迹。
- [x] 重复棋盘键包含双方节点、当前玩家和额外行动状态；说明未包含积分、回合数与随机流位置，不能据此证明无限循环。
- [x] 保存规则快照及版本、策略身份、种子、样本数、先后手与参数，统计能够追溯到完整行动记录。
- [x] 使用可人工核算输入验证统计、角色交换、配对差、重复键及配置身份。
- [x] 报告计划数量、完成数量、失败或跳过原因与覆盖范围，不把失败样本当平局或静默删除。
- [x] 非法配置、无法终局或运行错误返回非零退出状态；候选表现下降或未发现交叉不属于执行错误。
- [x] 基线与实验配置的端到端小规模冒烟测试通过，不以短批次胜率作为稳定回归断言。

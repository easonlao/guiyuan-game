# 02: 盘面听牌检测算法与 30 大回合推进模型

**What to build:**
核心状态与领域层提供纯函数式的听牌判定（`isBoardTingPai`：未点亮侧数 ≤ 2 判定为听牌临界态，即单回合内配合抽卡与爆发具备理论归元可能）；同时重构对局回合推进模型为规范统一的 30 大回合模型（每个大回合包含双方轮流行动各 1 次，连动额外行动不计入大回合计数），为智能快刀终局裁决提供精确的底层状态支撑。

**Blocked by:** None (can start immediately)

**Status:** closed

- [x] 核心状态层 (`State.ts`) 新增纯函数 `countLightedSides(board)` 计算盘面已点亮（≥1）侧数。
- [x] 核心状态层新增纯函数 `isBoardTingPai(board)` 准确判定盘面是否处于听牌临界态（剩余未点亮侧数 ≤ 2）。
- [x] 回合推进状态机规范对齐 30 大回合（Round）生命周期（每个大回合由 P1 行动与 P2 行动两半回合组成）。
- [x] 编写并运行单元测试覆盖各类盘面形态（0~10 侧点亮）的听牌判定边界与大回合计数流转。
- [x] 既有状态与回合单测保持全部通过。

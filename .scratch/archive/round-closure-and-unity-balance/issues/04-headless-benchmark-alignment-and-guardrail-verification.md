# 04: 无头推演引擎对齐与万局平衡性/性能护栏回归测试

**What to build:**
更新项目内的自动化推演工具链 (`HeadlessMatch` 与 `HeadlessBenchmark`)，使其完全对齐 30 大回合模型、归一 +60 分奖励及智能快刀闭合终局判定。通过自动化万局批量无头对弈，验证同策略自对弈先手胜率收敛至 50%~51.5%、同水平归元率保持在 80%~95%、技术型 AI 相对随机打法胜率达到 ≥65%，且单局推演平均耗时稳定在 <0.3ms（满足 ADR 0001 的各项平衡性与性能护栏）。

**Blocked by:** 03: 智能快刀终局裁决与听牌绝地追平全链路

**Status:** closed

- [x] `HeadlessMatch` 对齐智能快刀判定与 30 大回合生命周期。
- [x] `HeadlessBenchmark` 批量推演支持输出同轮双归元、常规秒结与终局形态完整度量。
- [x] 执行 10,000 局以上自动化推演，验证先手胜率严密落在 [48.5%, 52.0%] 区间。
- [x] 验证跨策略对弈中追归元策略对吃分流及随机策略的主导优势（强对弱 ≥65%）。
- [x] 自动化测试套件 (`npm test`) 与构建流程 (`npm run build:minigame`) 保持 100% 绿灯。

# 01: 节点归一里程碑奖励 (+60分) 与终局道损结算全链路

**What to build:**
玩家在对局中每次通过吸纳、调息、相生化气等操作使己方某个五行元素节点首次达成“归一”（阴阳双侧均达到 ≥1 时），立即在对局总分中斩获一次性 +60 分的里程碑奖励分。在对局达到回合上限进行终局结算时，双方盘面上残留的每个道损（-1）严格扣除 50 分。这从数学期望上使追求归元的动作收益显著压制单纯的攻击拆台，从根源上治愈吃分流互搏拖满回合的死局。

**Blocked by:** None (can start immediately)

**Status:** resolved

- [x] 核心计分配置中声明 `GUI_YI_MILESTONE: 60` 及终局道损扣分配置（-50 分/残留道损）。
- [x] 动作解析器 (`ActionResolver`) 在执行任意合法动作后，检测己方归一节点增量，每新增 1 个归一节点即赋予 +60 分并累加到 `scoreDelta` 及玩家总分中。
- [x] 终局上限结算流程中正确执行残留道损结算惩罚（每个 -1 扣除 50 分）。
- [x] 编写并运行单元测试覆盖各类动作触发归一时的 +60 分发放及终局扣分逻辑。
- [x] 现有单元测试与计分行为断言全部保持绿灯通过。

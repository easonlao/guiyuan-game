# 05: 第一阶段扫描与平衡体检报告

**What to build:** 在正式计分基线下，扫描 回合上限（12/20/30/45/60）× 电脑强度（规则式 / 搜索深度 1 / 搜索深度 2，含两组权重），输出由数据生成的平衡体检报告。只测量，不提出规则修改结论。

**Blocked by:** 01 — 输方 500 分诊断；03 — 报告由数据生成；04 — 搜索型策略

**Status:** closed

- [x] 每个组合 ≥200 种子、交换先手；报告有效样本与运行耗时。
- [x] 每个组合输出 6 项指标：
  1. 五行归元获胜占比及平均达成回合
  2. 先手胜率（基准 50%，附区间）
  3. 回合上限结算的分差分布与输方得分分布
  4. 逆转率（以回合上限一半处的分数/点亮落后定义"中盘落后"，口径写入报告）
  5. 排除强制吸纳后的动作选择占比与每局真实决策次数
  6. 同种子下强电脑对弱电脑的胜率
- [x] 给出五行归元占比随回合上限、强度变化的曲线或表格。
- [x] 结论按"问题—证据—边界"组织，所有结论引用数据；允许"证据不足"。
- [x] 报告写入 `reports/balance-diagnostics/phase1/`，附配置身份、源码哈希与重放入口。
- [x] 不修改正式规则或正式计分；计分方案对比留待第二阶段。

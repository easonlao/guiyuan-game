# 02: 2.5倍攻击压制状态分与爆发动作稀有度黑名单豁免实装

**What to build:**
让玩家对敌方节点造成压制破坏时，按目标节点被削弱的程度准确斩获 2.5 倍强化状态分（致阳道损 300 / 致阴道损 250、破阳点亮 200 / 破阴点亮 150、削弱加持 200）；同时让普通动作可应用稀有度加成（1.5x），而 BURST 与 BURST_ATK 严格被稀有度黑名单拦截豁免，消除爆发刷分垄断。

**Blocked by:** 01: 双轨制行为分与己方建设状态分全链路实装

**Status:** completed

- [x] 在计分配置中硬编码实装 ADR 0002 规定的 2.5 倍攻击压制状态分常量 (CAUSE_DMG 阳 300 / 阴 250, BREAK_LIGHT 阳 200 / 阴 150, WEAKEN 200)。
- [x] 在计分配置中配置稀有度黑名单 NO_RARITY_ACTIONS (['BURST', 'BURST_ATK']) 与默认稀有度乘数 (1.5)。
- [x] 计分器实现稀有度过滤机制：当动作为普通动作时支持应用稀有度乘数；命中黑名单动作时直接返回原值。
- [x] 动作解析器 (ActionResolver) 在 ATK 与 BURST_ATK 减法逻辑中完整计算攻击状态分，并与行为分正确汇总结算。
- [x] 外部行为切缝测试覆盖全部 3 类敌方状态破坏场景在阴阳两极下的得分断言，以及爆发动作稀有度豁免断言。

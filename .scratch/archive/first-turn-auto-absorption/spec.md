# 游戏开局首轮与虚空单一动作自动吸纳规范

## 目标

解决游戏在开局首轮（所有节点均为虚空 0）以及后续抽中虚空/道损天干时，P1（玩家）因缺乏自动推进机制而停滞等待手动点击的问题，确立纯粹合规的自动吸纳体验：

1. **唯一动作自动流转**：当 P1 抽中虚空/道损天干导致动作仅有唯一 `AUTO` 时，系统自动倒计时触发吸纳，无需强制玩家手动点击。
2. **轻量交互与即时跳过**：倒计时给玩家提供天干降临缓冲（约 0.6~0.8 秒），期间支持主动点击屏幕或按钮立即完成吸纳。
3. **简明视觉提示**：自动吸纳期间，横幅副标题展示为“自动吸纳中”。
4. **多分支安全保护**：一旦玩家存在任何其他分支选项（调息、化、破、强化、强破），严禁自动推进，严格等待玩家自主操作。

# 01: P1 虚空唯一吸纳自动推进调度引擎

**What to build:**
让玩家（P1）在面对唯一 `AUTO` 动作（如开局第 1 回合首轮全虚空或后续抽中虚空/道损天干）时，无需强制手动点击按钮即可自动执行吸纳流转：
1. 当 P1 回合开始且可用动作仅有单一 `AUTO` 时，启动自动吸纳调度计时器（默认约 40~50 帧，约 0.6~0.8 秒缓冲）；
2. 计时器在主循环中推进，归零时自动触发飞弹发射与动作执行（`dispatchAction`）；
3. 支持玩家在此期间任意点击屏幕或按钮立即完成吸纳（无需等待倒计时结束）；
4. 若当前可用动作不止一个（如存在点亮节点可调息、相生化、相克破或爆发），严禁触发自动吸纳计时器，保持完全等待玩家决策；
5. 提供单元测试覆盖自动推进生命周期的完整分支（自动触发、手动打断、多动作互斥）。

**Blocked by:** None (can start immediately)

**Status:** completed

- [x] P1 回合当且仅当候选动作仅有唯一的 `AUTO` 时，激活自动吸纳调度计时器。
- [x] 计时器归零时自动触发吸纳动作调度，推进回合与棋盘节点状态更新。
- [x] 倒计时期间玩家点击屏幕或按钮可立即跳过等待并执行吸纳。
- [x] 当 P1 拥有多个候选动作时，不激活自动计时，严格等待玩家决策。
- [x] 编写单元测试验证计时器生命周期、自动触发、主动跳过与多动作互斥逻辑。

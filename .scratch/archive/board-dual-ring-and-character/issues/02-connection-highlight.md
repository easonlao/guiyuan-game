# 02: 连线高亮语义

**What to build:** 盘面连线的高亮能告诉玩家「当前动作会走哪条路径」——相生边表「化/强化」、跨环径向线表「破/强破」，玩家抽中天干、可选动作确定后，对应的连线被点亮，让「破=径向向外、化=内环顺时针」这两个方向一眼可读。

**Blocked by:** 01 (法盘同心双环)

**Status:** resolved

连线本身（相生边 + 径向线）在票 01 已画出；本票只把「高亮」的语义从「源主印点不点亮」改成「当前动作会走哪条线」，信号来自当前天干与待定动作，而非盘面等级。

- [x] 相生边高亮对应「化/强化」的走向，径向线高亮对应「破/强破」的走向。
- [x] 高亮由当前天干与当前待定动作驱动，不再由「源主印任一侧点亮」驱动。
- [x] 5 条径向线常驻但极淡，当前动作对应的那一条高亮。
- [x] 无待定动作（自动流转/终局）时不误导性高亮。
- [x] 测试断言：给定天干与动作，正确的连线被标为高亮，其余不亮。

## Answer

连线高亮语义从「源主印任一侧点亮」改为「当前动作会走哪条线」：`BoardView.setActivePaths(paths)` 接收 `{kind:'generation'|'attack', from}` 集合，`connections[].isActive` 只由它决定；纯函数 `resolveActionPath(actionType, element)` 把 TRANS/BURST 映射到内环相生边、ATK/BURST_ATK 映射到跨环径向线、其余动作返回 `null`。`GameScene` 把阶段赋值收口到 `setPhase`，只在 `awaiting-player` 按当前天干 + 候选集生成路径，其余阶段（含 `auto-pending` 自动流转与终局）清空。

**取舍**：取候选集并集，不取「只亮第一个候选」——抉择阶段动作未定，高亮的作用是喂决策（spec 用户故事 3）；只亮第一个会让亮哪条线取决于候选数组顺序，选另一条时反而误导。同一根天干下候选至多映射出两条线，并集恰好覆盖「破 = 径向向外、化 = 内环顺时针」两个方向。自动流转虽确有唯一待定动作，但按票面「无待定动作（自动流转 / 终局）不误导性高亮」不亮。

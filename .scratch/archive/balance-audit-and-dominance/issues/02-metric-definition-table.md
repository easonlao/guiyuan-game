# 02: 指标口径表与陷阱回归测试 (Metric Definition Table)

**What to build:** 一份指标口径表，让每个指标「名字说的」和「代码真正在量的」一致，并把已确认的口径陷阱固化为回归测试。每个指标必须回答三件事：定义（用词汇表术语表述）、代码里实际怎么算、有没有一种局面会让它算出与直觉相反的结论。

三个已确认陷阱必须各自成为一条回归测试：

- 「加持 2 → 点亮 1」的削弱必须记为 1 而不是 0。此前按「未点亮侧数」统计把它记为 0，得出了「压制无价值」的相反结论。
- 自对弈归元率**不能**回答「某策略是否占优」。任何占优结论必须同时给出跨策略对拼矩阵。
- 单独输出流局率时必须附带先后手胜率。压制型策略同时表现为高流局率与偏离 50% 的先手胜率，两者是同一现象的两面。

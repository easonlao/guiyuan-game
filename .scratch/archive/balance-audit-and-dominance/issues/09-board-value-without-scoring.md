# 09: 剥离计分后的盘面价值 (Board Value Without Scoring)

**What to build:** 关掉计分轴后重跑跨策略对拼矩阵，用来分清「压制强是因为计分」还是「压制强是因为盘面节奏」。

现状下激进压制对全部其它五个策略严格占优。把【破】的计分归零确实会翻转最强策略——但那只说明**计分影响 AI 的取舍**，不能说明【破】在盘面上本身有没有价值，因为 AI 的压制偏好本身就来自计分差值。

**Blocked by:** 02 指标口径表与陷阱回归测试、06 策略族、实验运行器与对拼矩阵

**Status:** closed

- [x] 用同一套策略族，在「计分轴关闭、只按盘面判优」的条件下重跑完整对拼矩阵（含座次平衡）。证据：`docs/headless/board-value-without-scoring.md`（`da3b4ba`，并入 `5f0ae6b`）；`benchmark:board-only`。
- [x] 与现状对拼矩阵**逐格对照**，指出哪些格子的强弱关系发生翻转。证据：`docs/headless/board-value-without-scoring.md` 逐格对照表。
- [x] 明确回答：激进压制的严格占优是计分造成的、盘面造成的、还是两者叠加。证据：`2f80cdf` 修正版（AI + 终局结算双重剥离）裁定为**计分造成**，非盘面造成。
- [x] 顺带回答：现状的高流局率与压制型策略的先手优势是否也来自计分。证据：`docs/headless/board-value-without-scoring.md`（高流局来自盘面节奏；先手优势来自计分结算）。
- [x] 若盘面本身就让压制占优，明确指出——这意味着**单靠调计分无法修复**。证据：修正版证明盘面**不**让压制占优（盘面偏好推进），该条件未触发；结论为单靠调计分即有修复空间。

# 02: 调息对侧全状态边界矩阵与系统级回归验证

**What to build:**
构建严密的测试矩阵与系统级回归保障，彻底封死调息边界漏洞并确保全链路稳定性：
1. 边界测试矩阵：针对木、火、土、金、水全五行，覆盖抽中天干对应侧处于 1 或 2 时，对侧分别为 -1、0、1、2 的全部组合，穷举验证调息生成的准入与排斥边界。
2. 消散过牌边界覆盖：构造相生满溢、相克全损且调息受锁的典型死局场景，验证能够稳定触发消散过牌且不会导致棋盘死锁或异常加持。
3. 决策引擎与无头对局回归：验证 AI 策略评估器在面对消散过牌候选时能正确评估或保底流转，确保无头自动化对局、确定性策略测试以及性能基准全部绿灯。

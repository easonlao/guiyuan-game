# 01: 调息准入门槛收紧与消散过牌（PASS）接入

**What to build:**
严格按照 GDD 规范收紧调息动作与中位态无动作时的流转逻辑：
1. 调息门槛收紧：玩家抽中已点亮或加持的天干时，仅当该天干所属五行节点的对侧处于低位态（虚空 0 或道损 -1）时才允许调息；若对侧已处于点亮 (1) 或加持 (2)（如节点处于 (1, 1)、(1, 2)、(2, 1)），严禁生成或执行调息动作。
2. 消散过牌（PASS）接入：当中位态玩家面对当前天干无法执行调息、化、破或爆发中任何动作时（生克目标皆达极值且被锁调息/爆发），系统自动生成消散过牌（PASS）动作，行动后计 0 分并自然结束回合交接给对手，严禁原地回退为吸纳升 2。
3. 核心解析与既有测试对齐：动作解析器防御性拦截非法调息；更新核心测试中对 (1, 1) 等状态错误包含调息的既有断言，保持全套测试绿灯。

**Blocked by:** None (can start immediately)

**Status:** closed

- [x] 当抽中天干节点对侧处于点亮 (1) 或加持 (2) 时，候选动作列表中严格排除调息（CONVERT）。
- [x] 当抽中天干节点对侧处于虚空 (0) 或道损 (-1) 时，且满足中位态前提，调息动作正常可用。
- [x] 中位态下若所有合法行动（调息、化、破、爆发）皆不可行，系统生成消散过牌（PASS）动作，结算时得分变化为 0 并流转回合。
- [x] 动作解析器对目标侧等级已 >= 1 的非法调息请求进行防御拦截并返回失败。
- [x] 修正既有测试套件中在 (1, 1) 节点状态下误期待包含调息的断言，现有测试套件全部通过。

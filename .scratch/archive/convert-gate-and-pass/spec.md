# 调息准入门槛与消散过牌（CONVERT Gate & PASS Resolution）Specification

## 背景与问题描述

在《归元弈》GDD 与统一词汇表（GLOSSARY.md）规范中：
1. **调息 (CONVERT) 准入门槛**：当且仅当抽中天干对应侧处于中位态（点亮 1 或加持 2）且**同节点对侧处于低位态（虚空 0 或道损 -1）**时才允许发动。若同节点对侧已经达到点亮或加持（>= 1，例如节点处于 (1, 1), (1, 2), (2, 1), (2, 2) 状态），严格禁止调息。
2. **中位态无动作时消散过牌 (PASS)**：若中位态（对应侧 >= 1）当前盘面受生克、爆发及调息规则限制，没有任何合法动作可选时（如阳干克制目标全损无法破、相生节点亢极无法化、未归一无法爆发且对侧非低位态无法调息），必须触发“消散过牌 (PASS)”，直接消耗本回合流转给对手，计 0 分，严禁回退为原地吸纳升 2。

当前代码中，候选动作生成逻辑误放行了对侧为 1 的调息动作（判定条件为 `< 2`），并在无合法动作时错误回退为了 `AUTO`，与 GDD 规范发生背离。

## 目标与范围

1. 收紧调息门槛：仅在同节点对侧处于低位态（<= 0）时生成与允许执行 `CONVERT`。
2. 规范中位态兜底：在中位态无动作可选时生成 `PASS` 动作，并在状态机与计分器中支持 0 分过牌流转。
3. 修正既有测试断言，构建全面的对侧状态矩阵单测，并通过系统级 AI 决策和无头对局回归。
